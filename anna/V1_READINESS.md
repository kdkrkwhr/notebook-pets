# Notebuddy 1.0 출시 기준 · 2026-10-10

## 판단

현재는 초기 프로토타입이 아니라 **핵심 기능을 갖춘 출시 후보 준비 단계**입니다. 0.2.x를 20%라는 진행률로 읽지 않습니다. 테스트 개수나 커밋 수를 완성도 비율로 환산하지 않습니다. 아래 증거 기반 통과 조건으로 1.0 여부를 판단합니다.

버전의 대상이 서로 다릅니다: 원본 Notebook Pets 0.2.0, Anna 제출 앱 0.2.1, 실행 도구 0.1.9. develop의 개선사항은 아직 Anna에 배포되지 않았습니다. 현재 출시 판단 대상은 Anna Notebuddy이며 원본/도구 버전을 숫자 맞추기 위해 바꾸지 않습니다.

## 1.0 범위 고정

한 파트너 돌봄, 1/10/30/50 성장, 일일 퀘스트, 산책/전투, 대화, 이전 모습에 기반한 자동 진화 그림과 앨범, 저장/복구, 명시적 초기화/삭제, 영어 기본·한국어 선택을 포함합니다. 기본 그림은 유년기 72종만 제공합니다. 사용자가 추가 승인한 선택형 사용자 작품 첫 만남은 사진·그림 확인과 참조 유년기 생성을 포함하며, 실제 생성 경로 검증 전에는 출시 완료로 보지 않습니다. 새 종족·추가 게임 모드·모바일·이름 기반 외형 장식·자동 돌봄 대사는 1.0 필수 항목이 아닙니다.

## 남은 실무 작업을 네 묶음으로 제한

1. **이미지 품질 검증:** 개발 계정에서 별도 개발 후보로 참조 지원 모델·URL 접근·4단계 외형을 실제 확인합니다. 새 구현은 develop에만 있어 현재 설치 앱으로는 검증할 수 없습니다. 기존 심사 후보를 바꾸는 배포는 이번 작업 범위가 아닙니다. 실패하면 프롬프트/모델 연결을 수정하고 이 항목만 다시 검증합니다.
2. **신규 설치 검증:** Anna 승인 후 일반 계정으로 실행해 설치/권한/저장 경로를 확인합니다. 서비스 로직 자동 테스트는 지금 수행하고, 실제 설치는 승인 후 수행합니다.
3. **1.0 후보 고정:** 위 문제를 해결한 소스의 최종 버전 번호, 개인정보 안내, 스크린샷, 빌드와 CI를 맞춰 기록합니다. 이후에는 버그 수정만 허용합니다.
4. **출시:** 실제 후보가 검증되고 공개 가능한 상태이면 1.0.0으로 배포합니다. 사용자가 실제 쓸 수 있는 공개 버전과 저장소의 버전을 함께 기록합니다.

이 네 묶음에 이름 꾸미기나 모바일 같은 신규 기능을 추가하지 않습니다. 개선 아이디어는 후속 버전으로 넘깁니다.

## 버전 진행 제안

0.3→0.4→0.9를 순서대로 거칠 필요가 없습니다. 현재 자동 진화 작업을 마친 소스를 **1.0 후보 범위**로 고정하고, 위 통과 조건을 만족하면 다음 정식 제품 버전을 **1.0.0**으로 올립니다. RC는 개발상의 상태 이름으로 사용할 수 있으며 Anna에 선행 버전 문자열을 실제 제출할 수 있는지는 아직 확인하지 않았습니다. 이 문서 작성만으로 버전 태그·manifest·심사 후보를 변경하지 않습니다.

## 수용된 위험을 완료로 바꾸지 않기

동시 최초 생성의 원자성, 오래된 실행기/진행 중 요청의 초기화·삭제 경합, 플랫폼 로그·백업 보관은 해결 완료가 아닙니다. 사용자는 이 제한을 명시한 채 심사 제출하도록 승인했습니다. 이 수용 결정을 그대로 기록하며 1.0을 전역 exactly-once나 무손실 보증으로 설명하지 않습니다. 새로운 데이터 손실 재현이나 보안 결함이 발견되면 출시 판단을 다시 검토합니다.

일반 지원은 공개 GitHub Issues이며 개인정보를 받지 않습니다. 별도 비공개 지원 창구를 확보했다고 주장하지 않습니다. 이름 기반 외형 반영은 사용자와 아이디어만 논의했고 구현 범위에 추가하지 않았습니다.
