## 새 펫으로 초기화 · 앱 0.1.10 / 도구 0.1.8

초기화 중에는 게임을 막고, 같은 reset ID로 생성 후보를 유지하며, 정리가 끝난 뒤에만 새 게임을 엽니다. 기존 행동 순번은 증가시켜 초기화 전 요청을 차단합니다. 재접속 후 초기화 이어하기와 완료 응답 유실 복구를 제공합니다. 영구 개인정보 삭제 표식은 여전히 초기화할 수 없습니다. [구조와 동시성 제한](archive/RESET_HISTORY.md), [사용자 데이터 안내](PRIVACY.md)를 확인하세요.

XP나 게임 보상을 변경하지 않았습니다. 창을 닫고 다시 열어 `nb2:1:`, 모찌 10 XP, 대화 2개, AI 초상화의 정상 로딩을 확인했습니다. 새 파트너·유료 AI 대화·이미지를 생성하지 않았습니다. 이 계정의 게임 저장은 이제 새 envelope 형식이므로 도구 0.1.4 이하로 되돌리지 마세요.

0.1.4 점검 당시 Listing에서 스크린샷·cover·privacy URL이 비어 있었습니다. 0.1.5에서 스크린샷과 privacy URL을 등록했고 cover는 비워 두었습니다. [REVIEW_READINESS.md](archive/REVIEW_READINESS.md)에 플랫폼 필수 조건과 프로젝트 출시 차단 항목을 구분했습니다. 심사 승인과 동시에 공개될 수 있으므로 아직 제출하지 않습니다.

## 최초 생성 보호 보강 · 비공개 배포 확인

앱 0.1.3 / 도구 0.1.4를 비공개 초안에 배포했습니다. 최초 생성 계산 후 재확인, 독립 서비스 경합 회귀 테스트, 운영 계약에 맞춘 테스트 저장소, 미해결 경합 재현 도구를 추가했습니다. Anna Python 24개·UI 10개·strict 검사와 Windows/Linux CI 및 패키지 빌드를 통과했습니다. Install draft 후 앱 창을 닫고 다시 열어 정상 연결, 모찌(기계족/물), 10 XP, 기존 대화 2개, AI 초상화 복원을 확인했습니다. 기존 파트너를 새로 생성하거나 게임 행동·유료 AI 호출을 실행하지 않았습니다.

첫 생성 경합은 실제 사용자 저장에서 파괴적으로 재현하지 않았습니다. 오프라인 APS 계약 모델의 재현은 여전히 종료 코드 1이며, 이 릴리스는 위험을 줄이는 보호 조치입니다. 분산 최초 생성 문제를 해결 완료로 표시하면 안 됩니다.

## 영어 기본·한국어 선택 적용

- Anna 화면·게임 결과·오류 안내는 영어가 기본이며, 헤더에서 한국어로 전환합니다. AI 대화 프롬프트도 선택 언어를 명시합니다.
- 언어는 브라우저 `localStorage`의 `notebuddy/language-v1`에 저장됩니다. 계정 전체나 다른 기기와 동기화되는 설정은 아닙니다. 저장이 차단되면 현재 창에서만 적용하며 안내합니다.
- 엔진 상태와 요청 영수증은 기존 형식 그대로 저장하고 응답만 번역합니다. 언어를 바꿔 같은 요청을 재시도해도 중복 지급되지 않는 테스트를 추가했습니다.
- 사용자 이름과 과거 대화는 원문을 유지합니다. 기존 파트너를 다시 생성하거나 저장 형식을 마이그레이션하지 않습니다.
- 실제 설치 앱에서 영어 기본 화면, 한국어 전환, 창을 닫고 다시 연 뒤 한국어 설정 유지, 영어 복귀를 확인했습니다. 모찌(기계족/물), 10 XP, 기존 대화와 AI 초상화가 유지됐습니다.
- 초안 적용 직후 첫 창은 연결 대기에 머물렀으나 iframe 새로고침 후 정상 연결됐고, 이후 앱 창 재실행도 정상 동작했습니다. 원인을 확정한 것은 아닙니다.
- 모바일 폭의 영어·한국어 가로 넘침은 로컬 브라우저에서 확인했습니다. AI 답변의 언어 지시는 자동 테스트로 검증했고, 이번 언어 변경 검증에서 유료 AI 대화·그림은 새로 생성하지 않았습니다.
- README 한·영 안내와 Anna 영문 개발 문서를 갱신했습니다. 루트 게임 버전은 0.2.0을 유지하고 Anna 앱/도구 버전만 올렸습니다.

## 이번에 해결한 실제 설치 오류

기존 설치 앱의 화면은 열렸으나 `game/status`가 APS 권한 오류 **-32021**로 실패했습니다. 앱 권한 화면은 허용 상태였지만 Executa의 `host_capabilities`가 비어 있었습니다. `storage` 구조만으로 로컬 테스트는 통과했으나 실제 실행에서 실패한 사례입니다.

게임 도구의 코드 및 배포 manifest에 **`aps.kv`**를 명시하고 비공개 초안과 도구 manifest를 동기화한 뒤 실제 설치 경로가 정상 동작했습니다. UI도 이 오류를 일반 연결 오류로 숨기지 않고 저장 권한 확인 방법을 안내합니다. manifest/프로토콜/버전 일치 검사를 추가했습니다.

## 공개 전에 남은 작업

1. **동시 최초 생성 — 출시 차단 유지**: 사용자 결정에 따라 Anna 원자적 생성 지원 확인까지 보류합니다. 도구 0.1.4에서 첫 저장 직전 재확인을 추가했지만 최종 조회/쓰기 간격의 경합은 남습니다. [FIRST_CREATION.md](docs/FIRST_CREATION.md)의 재현 도구는 원본 파트너·10 XP 덮어쓰기를 재현하고 의도적으로 종료 코드 1을 반환합니다. 이 결과를 정상 회귀 테스트 통과와 혼동하지 마세요. 외부 서버 도입·Anna 문의 전송은 하지 않았습니다.
2. **게임 기록 누적 대응 구현**: 앱 0.1.4 / 도구 0.1.5에 순번 기반 재시도와 64개·24KiB 영수증/48KiB 전체 저장 제한을 구현했습니다. [STORAGE_POLICY.md](docs/STORAGE_POLICY.md) 참조. 앱별 대화의 바이트 한도, 오래된 초상화 파일, 계정 전체 용량은 별도 범위입니다.
3. **스토어 정보**: 실제 앱 화면의 소개용 스크린샷과 개인정보/데이터 처리 안내 URL은 아직 비어 있습니다. 대화·이미지·게임 저장의 처리 및 삭제 방법을 실제 동작에 맞게 정리해야 합니다.
4. **기존 운영 도구 적용 범위**: 로컬 파일용 백업·비활동 페널티 작업은 APS 세이브에 연결되어 있지 않습니다. 원본과 동일한 운영 동작으로 설명하면 안 됩니다.
5. 위 검증을 마무리한 후 심사 제출 여부를 결정합니다. 현재 상태를 공개 완료로 설명하지 마세요.

## 재개 방법과 주의점

`anna/README.md`의 로컬 실행 절차를 사용합니다. CLI는 `@anna-ai/cli 0.1.57`, SDK는 uv.lock의 Git 커밋에 고정되어 있습니다. 로그인은 공식 기기 인증으로 갱신했습니다. 토큰은 사용자 설정 폴더에 있으며 Git에 포함하지 않습니다.

- `apps push --no-install-local --profile binary`는 작업 초안을 갱신합니다.
- `apps cut <새 버전>`은 실행 파일을 업로드하고 도구 의존성을 고정합니다. 기존 버전 번호를 재사용하지 마세요.
- Install draft 후 기존에 열려 있던 앱 창은 예전 버전을 가리킬 수 있습니다. **앱 창을 닫고 다시 열어** 검증합니다.
- `already_satisfied`는 추가 배포가 생략되었다는 뜻입니다. 그 문자열만 보고 실행 실패라고 결론 내리지 말고 실제 앱 상태 조회를 확인합니다.
- 이 PC의 WSL 조회가 `REGDB_E_CLASSNOTREG`로 실패하여 Linux 빌드는 GitHub CI에서 수행했습니다. 사용자 OS 설정은 변경하지 않았습니다.
- 개발 앱 ID 451/452/453과 본 앱 450의 저장은 별개입니다.
- Orca 캡처·진단 파일은 작업용 workspace에만 있으며 Git에 포함하지 않았습니다. iframe URL에는 임시 인증 토큰이 있으므로 경로만 출력하세요.
