# Anna 심사 준비 현황

2026-10-09 확인. 기능이 실행되는 상태와 심사를 통과한 상태는 다릅니다. 최종 승인은 Anna 심사자의 판단이며, 현재 앱은 비공개 초안입니다.

## 확인 완료

- 영문 기본 화면·소개, 한국어 선택, 이름·기존 대화 보존.
- 최초 파트너 생성, 돌봄, AI 대화·이미지 저장, 재접속 복원은 설치된 Anna 앱에서 확인한 기록이 있습니다.
- Executa 저장 권한(`aps.kv`), manifest strict 검사, Windows/Linux 회귀 테스트와 배포 파일 검증.
- 요청 결과의 수·크기 제한과 순번 기반 재실행 방지. 자세한 저장 계약·구버전 제한은 [STORAGE_POLICY.md](STORAGE_POLICY.md).
- 실제 Listing 화면에서 이름, 카테고리, 영문 설명, 로고, 홈페이지와 지원 URL 등록을 확인했습니다.

## 출시 전에 남은 일

| 순서 | 항목 | 상태와 완료 기준 |
| --- | --- | --- |
| 1 | 동시 최초 생성 | **프로젝트 자체 출시 차단 항목.** 사용자 결정대로 Anna의 원자적 최초 생성 지원 확인까지 유지합니다. [재현과 문의 초안](FIRST_CREATION.md)은 준비됐지만 문의를 보내지는 않았습니다. 지원되는 API로 여러 실행기의 최초 생성·지연 요청을 검증해야 합니다. |
| 2 | 데이터 처리·삭제 안내 | [영문 데이터 안내](PRIVACY.md)와 앱 내 한·영 안내창, Privacy URL을 준비했습니다. **전체 삭제 경로는 미해결**입니다. Anna Storage 화면은 이 앱의 app/tool 범위를 모두 삭제하는 경로로 검증되지 않았고 Installed Apps의 제거도 데이터 삭제를 보장하지 않습니다. 진행 중인 저장의 재생성까지 막는 인증된 삭제 경로와 비공개 지원 연락 방법을 출시 전에 확정해야 합니다. 공개 GitHub 이슈에 개인정보를 올리지 않도록 안내합니다. |
| 3 | 스토어 이미지 | [영문 실제 UI 캡처 3장](store/README.md)을 준비하고 Listing에 등록할 파일을 연결했습니다. 격리된 로컬 엔진으로 생성한 테스트 파트너이며 사용자 계정의 대화를 공개하지 않습니다. 최종 후보 화면과의 일치 확인은 남아 있습니다. 선택 항목인 Cover URL은 비워 두었습니다. |
| 4 | 심사 후보 최종 검증 | 최종으로 cut한 버전을 기준으로 신규 설치, 권한 허용, 저장 이행, 행동 재시도, 재접속, 좁은 화면, 오류 복구를 확인합니다. 현재 manifest는 별도의 mobile 지원을 선언하지 않으므로 모바일 인증 완료로 설명하지 않습니다. |
| 5 | 심사 제출·피드백 | 위 항목이 끝나면 후보 버전을 고정하고 제출합니다. 반려 사유가 오면 수정 후 재제출합니다. 승인 여부·일정은 보장할 수 없습니다. |

게임 기록 크기 제한이 계정 전체의 용량이나 이미지 정리를 해결하는 것은 아닙니다. 오래된 초상화 파일 정리, 대화의 바이트 한도, APS용 백업·비활동 페널티는 적용 범위를 따로 검토해야 합니다. 현재 소개문에는 원본 Discord의 모든 운영 기능이 Anna에서도 제공된다고 쓰지 않습니다.

## 플랫폼 요구사항과 프로젝트 판단의 구분

[Listing Fields](https://anna.partners/developers/apps/app-listing.md)에서 이름·slug·카테고리는 필수이고, 스크린샷·privacy URL·cover URL 등은 등록 스키마상 선택입니다. 빈 선택 필드만으로 자동 반려된다고 단정하지 않습니다. 다만 대화와 이미지를 저장하는 이 앱에서는 사용자 설명과 실제 화면 자료를 준비하는 것이 적절합니다.

[Publishing an App](https://anna.partners/developers/apps/app-publish.md)은 유효한 manifest, 고정된 Executa 연결, 준비 완료된 UI bundle, 개발자의 설치·종단 간 사용 검증을 제출 전 점검 대상으로 명시합니다. 심사자는 실제 동작과 소개/스크린샷의 일치를 확인하며, mobile을 선언한 경우 모바일 체크리스트도 확인합니다.

공식 문서에는 관리자가 `publish: false`로 승인만 하거나 `publish: true`로 승인과 공개를 함께 할 수 있다고 적혀 있습니다. 현재 콘솔은 승인 즉시 공개된다고 안내했습니다. 따라서 **심사 제출을 공개 가능성이 있는 단계로 취급**하고, 출시 차단 문제가 남은 상태에서는 제출하지 않습니다. 이 문서는 문의·심사 제출·공개를 실행했다는 기록이 아닙니다.
