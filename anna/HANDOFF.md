# 1.4.4 · Anna·웹 공통 일곱 가지 테마 · 2026-10-16

앱 **1.4.4 / ID 1416 / working revision 58**, 변경 없는 도구 **0.9.1 / Executa version 760**. Anna 소스 **`bc1110bfbb32ff7c9d1741dc2065412f2c028866`**. 소유자 테스트 설치 `0.0.0-draft`, `dirty_vs_latest_cut=false`. 심사 후보 **1.0.0 / ID 1383 / pending_review** 유지.

- 상단 **◐ 테마**에서 기본 공책·고요한 밤·지옥문·얼음왕국·몽환의 숲·침몰한 왕궁·잊혀진 태엽도시를 고른다. 즉시 적용·다음 실행 유지, 한·영 표시·키보드 선택·모바일 배치를 지원한다. 게임 연결 중에도 사용할 수 있다.
- 대화·돌봄·도감·홈 상점·타이틀 UI에 적용하며 캐릭터 그림과 홈·던전 캔버스 색은 유지한다. 선택은 로컬 `notebuddy/theme-v1`에만 저장하고 AI·게임 도구·계정 저장소를 호출하지 않는다. 게임 초기화는 유지하고 Anna 전체 데이터 삭제 성공 시에는 지운다. 브라우저 저장이 불가하면 현재 세션에만 적용한다.
- 로컬 **JS 89 / 브라우저 102 / strict** 통과. 7개 즉시 전환·재실행·잘못된 설정·저장 실패·한영·키보드·1120/360px·새 테마 주요 글자 대비·게임/AI 무호출을 확인했다. [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38845285509) Windows/Linux/Pyodide 성공. [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38845285490) Windows/Linux UI·브라우저·저장/프로토콜·패키지 자체 검사 성공.
- 실제 설치 앱 **Connected**, 7개 테마 적용/저장과 재실행 후 타이틀 유지 확인. 검증 후 소유자의 원래 테마 설정으로 돌렸다. 테마·앱·홈·던전 코드 **10개 HTTP 200 / SHA-256 일치**. HTML 직접 fetch는 Anna에서 403을 반환하여 HTML 해시는 비교하지 않았으며, 설치 프레임의 실제 DOM과 동작으로 새 화면을 확인했다.
- 클라우드 도구 **0.9.1 / loaded=true / running=true**. 기존 Windows/Linux 0.9.1 패키지 2개를 재사용했고 설치 응답은 `already_satisfied`다. 도구 변경·새 버전은 없으며 오프라인 PC 실행은 이번에 확인하지 않았다.
- 게임·아트·대화·이야기·성격 초안 **5종 값과 ETag 모두 배포 전후 동일**. 공유 소개·스크린샷 **6개**·심사 상태도 동일하다. 재심사·Anna 공개 출시는 하지 않았다. [배포 기록](releases/RELEASE_144.md).
- 같은 변경을 Git merge로 `release-web`에 통합했다. 공개 웹 **0.4.1**, 소스 **`19dd9c8f6905895b313cf9aaf9b50bfaa2e614e8`**, [Pages CI·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38845484168) 성공. 실제 공개 URL의 격리된 테스트 공책에서 7개 테마·재실행·1120/360px·홈·도감·AI 설정을 확인했다. 저장 스냅샷 동일·AI 0회·페이지 오류 0, 코드/코어/아트 **19개 해시 일치**(텍스트 줄바꿈 정규화). 사용자 웹 저장소는 건드리지 않았다.
- 제한: 테마는 실행 환경별 로컬 설정이며 Anna·웹·다른 기기 사이 동기화나 게임 백업 대상이 아니다. 실제 유료 AI는 이번 UI 작업에서 호출하지 않았다. 기존 이미지 생성 품질·계정 할당량·아바타 착용 제한은 그대로다.

# 1.4.3 · 이미지 변경 시 동작 준비, 홈·던전 공동 사용 · 2026-10-16

앱 **1.4.3 / ID 1413 / working revision 57**, 변경 없는 도구 **0.9.1 / Executa version 760**. 배포 소스 **`895ffa99dd573bc223f371fc4448a52c5a256273`**. 소유자 테스트 설치 `0.0.0-draft`, `dirty_vs_latest_cut=false`. 심사 후보 **1.0.0 / ID 1383 / pending_review** 유지.

- 수동 동작 생성·재생성 버튼을 제거했다. 새 친구 생성(랜덤 포함), 새 초상화·새 진화 그림 저장 시 현재 그림으로 동작을 이미지 AI 한 번에 준비한다. 성장 단계 숫자만 바뀔 때는 생성하지 않는다. 홈·던전 열기, 이동, 재입장, 저장 재시도에도 AI를 쓰지 않는다.
- 같은 원본의 요청 예약을 조건부 저장해 중복 저장·동시 창·응답 유실 후 AI 재요청을 억제한다. 실패해도 친구와 원본은 유지한다. 이미 받은 결과의 저장 재시도만 제공한다. 아바타 착용은 아직 없으며, 추후 최종 착용 그림은 동일한 `syncPortraitVisuals` 흐름을 사용한다.
- 홈과 던전은 같은 개인 스프라이트와 프레임 렌더러를 사용한다. 던전의 이동 방향에 따라 걷는 자세가 바뀌며 새 동작에는 초상화 회전·흔들기를 적용하지 않는다. 동작이 없는 기존 친구나 다운로드 실패는 그 친구의 초상화로 대체 표시한다.
- 로컬 **JS 89 / 브라우저 99 / strict** 통과. [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38833400645) Windows/Linux/Pyodide 성공. [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38833400650) Windows/Linux UI·브라우저·저장/프로토콜·패키지 자체 검사 성공. 도구 소스가 같아 앞서 검증·배포한 두 OS의 0.9.1 패키지를 유지했으며 새 도구 버전은 만들지 않았다.
- 실제 설치 앱 **Connected**, 오류 안내 없음. 생성 버튼 제거, 기존 소유자 홈 동작 ready, 지옥문 미리보기의 `sprite=home`을 확인하고 화면을 캡처했다. UI 코드 8개 HTTP 200 / 로컬 SHA-256 일치. 실제 이동은 소유자 이미지를 넣은 별도 테스트 화면에서 검증했다. 실제 탐험 입장·보상·AI 생성은 실행하지 않았다.
- 클라우드 도구 **0.9.1 / loaded=true / running=true**. 설치 응답 `already_satisfied`로 기존 실행 도구를 재사용했다. PC는 오프라인이므로 해당 PC 실행 상태는 확인하지 못했다.
- 게임·아트·대화·산책 이야기·성격 초안 **5종 값과 ETag 모두 배포 전후 동일**. 기존 심사·공유 소개·스크린샷 6개도 동일하다. 재심사나 공개 출시는 하지 않았다. [배포 기록](releases/RELEASE_143.md).
- 남은 제한: 실제 Anna 참조 이미지 생성은 계정 사용량 부족으로 미검증이다. 생성 실패는 자동으로 AI를 재호출하지 않으며 다음 새 그림에서 준비한다. 저장 전 결과는 페이지를 닫으면 유실될 수 있다. 외형·방향의 의미상 정확도, APS 최초 생성 경합과 아바타 착용 미구현은 [안내](docs/HOME_PIXEL_ART.md)를 따른다.
