# 1.1.2 · 확장 지역 아이템 8종·도감 24종 · 2026-10-15

앱 **1.1.2 / ID 1394 / working revision 51**, 도구 **0.7.0 / Executa version 752**. 소스 **`e16c50bf84526597722bc507cb9953f68a142f8d`**를 푸시하고 불변 버전을 만들었다. 소유자 테스트 앱은 같은 내용의 `0.0.0-draft`로 설치됐으며 `dirty_vs_latest_cut=false`다. 심사 후보는 **1.0.0 / ID 1383 / pending_review** 그대로다.

- 침몰한 왕궁·잊혀진 태엽도시에 머리·목·등·주변 효과 아이템을 각각 4종 추가해 도감이 총 24종이 됐다. 산호 진주 왕관·작은 태엽 무리는 희귀 미리보기다. 한국어·영어 설명, 지역·부위 필터, 검색, 예정 획득 방법과 착용 기준을 연결했다.
- 투명 PNG 8개를 내장 이미지 도구로 개별 생성해 원본 그대로 포함했다. 도감 열람에는 AI 호출이 없다. 수집·구매·착용·실제 던전 보상은 변경하지 않았다. 한국어·영어 README에 실제 UI로 촬영한 전체 도감·상세·모바일 스크린샷 3장을 넣었다.
- 로컬 JS **81/81**, 브라우저 **90/90**, strict 통과. 도감 테스트는 새 지역 8종의 그림 디코딩·설명·필터와 AI/저장 변경 없음, 360px 한국어 화면을 확인한다. 문서 9개·로컬 링크 156개·이미지 11개 검증. [엔진 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38708748960) 성공, [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38708749027) Windows/Linux 모두 성공(저장·프로토콜·패키지 빌드 및 자체 실행 검사 포함).
- `apps push` revision 51, `apps cut 1.1.2` ID 1394, 테스트 설치 완료. Windows/Linux 도구는 기존 0.7.0 패키지와 SHA-256이 같아 캐시된 패키지를 재사용했다. 설치 후 **PC·클라우드 모두 agent_version=0.7.0, loaded=true, running=true** 확인.
- 실제 설치 화면에서 **Connected**, 오류 안내 없음, **24종 및 새 지역별 4종**, 새 아이템 **8개 상세 이미지 및 전체 24개 그림 디코딩**을 확인했다. 설치 경로의 코드·그림 **12개가 HTTP 200 및 로컬 SHA-256 일치**. 중복 열린 창을 새로고침하는 동안 한 창의 상태 요청이 일시 시간 초과했으나 최종 단일 창에서 새로고침·재확인해 정상 연결을 확인했다.
- 저장소 게임·아트·대화·산책 이야기·성격 초안 **5종의 값과 ETag가 배포 전후 동일**. 공유 소개 필드·스크린샷 6장·심사 상태도 스냅샷과 정확히 같다. 게임 행동·산책 소모·실사용 AI 호출·심사 재신청·공개 출시는 하지 않았다.
- 제한: 도감은 미리보기이며 실제 획득·착용은 후속 작업이다. 플랫폼의 동시 최초 생성 경합은 기존 [제한](FIRST_CREATION.md)으로 남는다. [전체 배포 기록](releases/RELEASE_112.md) · [아이템과 생성 프롬프트](ITEMS.md).

# 1.1.1 · 확장 던전 아트·안내 및 테스트 배포 완료 · 2026-10-15

앱 **1.1.1 / ID 1393 / working revision 50**, 도구 **0.7.0 / Executa version 752**. 소스 **`0b0d3496b35e6b1b296f9db097ba18de6f95ed70`**를 푸시하고 불변 버전을 만들었다. 소유자 테스트 앱은 같은 내용의 `0.0.0-draft`로 설치됐으며, `dirty_vs_latest_cut=false`다. 이 기록은 테스트 배포이며 심사 후보는 **1.0.0 / ID 1383 / pending_review** 그대로다.

- 침몰한 왕궁·잊혀진 태엽도시의 발견 카드 그림과 보스 3자세 스프라이트를 추가했다. 배경 그림은 발견 카드용이며 실제 탐험은 기존 방·복도 맵을 사용한다. 게임 규칙·저장 구조·실행 중 AI 호출은 추가하지 않았다.
- 한국어·영어 README와 Anna 안내를 다섯 던전 기준으로 갱신하고 실제 UI에서 촬영한 새 발견 카드 2장을 첨부했다. 앱·npm·루트 버전을 1.1.1로 맞췄다. 아이템 16종은 도감 미리보기 단계이며 수집·착용은 이후 기능이다.
- `apps cut 1.1.1` 완료. Windows/Linux 도구는 이전에 빌드·검증한 0.7.0 패키지와 해시가 같아 재사용했다. 설치 후 **PC·클라우드 모두 agent_version=0.7.0, loaded=true, running=true**를 재조회했다. PC 선택을 위해 잠시 바꾼 기본 에이전트는 기존 클라우드로 복원했다.
- 설치된 Anna 앱을 새로고침해 **Connected**, 오류 안내 없음, 기존 캐릭터·픽셀 그림 정상 로딩을 확인했다. 실제 설치 경로의 JS·이미지 **7개 모두 HTTP 200 및 로컬 SHA-256 일치**. 발견하지 않은 던전을 열려고 실제 게임 데이터를 바꾸거나 산책을 소비하지 않았다.
- 로컬 JS **81/81**, 브라우저 **90/90**, strict 검사 통과. [엔진 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38701415414)와 [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38701415506)가 Windows/Linux 모두 성공했다. Anna CI에는 저장·프로토콜 검사와 실행 패키지 빌드·스모크 테스트가 포함된다.
- 저장소 게임·아트·대화·산책 이야기·성격 초안 **5종의 값과 ETag가 배포 전후 동일**하다. 공유 소개 필드와 스크린샷 6장, 심사 상태도 이전 스냅샷과 정확히 같다. 공개 출시·심사 재신청은 하지 않았다.
- 이전 1.1.0 기록의 미완료 배포 항목은 이번 1.1.1에서 마무리했다. 플랫폼의 동시 최초 생성 경합은 기존 [제한](FIRST_CREATION.md)으로 남는다. [전체 배포 기록](releases/RELEASE_111.md) · [새 아트와 생성 프롬프트](../assets/dungeons-v2/EXPANSION_111.md).
