# 1.4.5 후속 · 일반 전투·던전 규칙 안내 · 2026-10-16

사용자 요청에 따라 **규칙을 변경하지 않고** 한국어·영어 안내를 추가했다. 앱 **1.4.5**, 도구 **0.9.1**, 웹 **0.4.2** 버전을 유지한다. Anna 소스 `4f9257ebe6f222209de06b245a6f68b780808fe3`, 웹 소스 `e7d015d1badba958d9d860075f3d5732ce798ba2`.

- 승패 표시를 일반 전투로 명확히 하고 산책 중 야생 몬스터와의 전투만 집계하며 던전 결과는 포함하지 않는다고 안내한다.
- 던전 미발견·클리어·만료 후에도 발견 안내는 남기되, 미발견 던전 입장 카드는 노출하지 않는다. 다섯 지역·레벨 해금 없음·한 번에 한 던전·산책 25%·당일 클리어 지역의 한국 시간 자정 재편입을 설명한다.
- 발견 후 24시간 만료·자동 교체/타이머 초기화 없음·입장 완료 스테이지의 선택 보존, 새 탐험/패배 후 재도전 최대 HP·같은 탐험 내 체력 유지·쉼터 회복을 설명한다. HP 안내는 입장 버튼 위에 표시한다.
- 검증: JS **89**, strict 통과. 브라우저 **103** 통과. 웹 기본/저장/백업·홈/던전·7개 테마 통합 검사 통과. 로컬 웹 1120/360px·입장 안내·저장 스냅샷 동일·AI 0회·페이지 오류 0 확인.
- **Anna 배포 완료**: 사용자 로그인 승인 후 working revision **60** 업로드와 소유자 초안 **`0.0.0-draft`** 설치에 성공했다. 새 불변 버전은 만들지 않아 **1.4.5 / ID 1417 / pending_review** 후보와 공유 소개·스크린샷·로고·지원 링크를 유지했다. `dirty_vs_latest_cut=true`는 설명 변경이 테스트 초안에만 반영됐음을 뜻한다. 기존 Executa **0.9.1 / version 760**을 재사용했고 설치 응답은 `already_satisfied`, 클라우드 실제 플러그인 manifest **0.9.1 / enabled=true / running=true / last_error=null**을 확인했다. PC는 오프라인이며 도구 코드·패키지는 변경하지 않았다.
- 실제 검증: 설치 번들을 플랫폼의 공식 창 관리자·호스트 브리지에 연결해 **Connected**, 한국어·영어 승패/발견/만료/HP 안내와 실제 진행 중인 지옥문 선택의 보존, 360px 화면을 확인했다. 모의 게임/AI 응답은 쓰지 않았고 AI 호출 0·브라우저 예외 0이다. 개발자 PAT는 일반 대시보드의 브라우저 세션 로그인을 대신하지 못해 공식 WM/브리지를 별도 테스트 호스트에 올렸다. 사용자 일반 브라우저의 재접속은 별도 확인 범위다. 설치 번역·던전·CSS 3개 HTTP 200/SHA-256 소스 일치, HTML은 Node 인증 요청 HTTP 200/소스 일치 및 실제 DOM으로 확인했다(iframe 직접 fetch는 플랫폼 403).
- 설치 전후와 실제 화면 확인 후 앱 저장 **아트·대화·산책 이야기·성격 초안** 값/ETag 및 게임 개인정보 inspect 응답이 동일하다. 생성·전투·산책·구매·꾸미기·리셋·삭제는 실행하지 않았다. 개인 스냅샷·검증 화면은 Git 제외 `.local/anna-guidance/`에만 보관한다.
- 공개 웹 **0.4.2** 유지, [Pages 빌드·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38886276977) 성공. 실제 공개 URL의 HTML·공통 번역·던전·앱 JS가 로컬 빌드와 동일하며 1120/360px·새 친구의 미발견 안내·입장 HP/만료 설명·저장 스냅샷 동일·AI 0회·페이지 오류 0을 확인했다. 별도 브라우저 컨텍스트로 사용자 저장소를 격리했다. [release 공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38886273807)와 [웹 공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38886277180) Windows/Linux/Pyodide 성공. [Anna Windows/Linux CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38886273836)도 UI·브라우저·저장/프로토콜·패키지 검사를 모두 통과했다.

# 1.4.5 · 방향별 동작 일관성 보정과 심사 후보 교체 · 2026-10-16

추가 체형 검수: 같은 앱 명세로 내장 imagegen에서 원본 참조 시트를 4종 만들었다. 날개형 용·로봇·둥근 새는 16프레임과 실제 크기·홈 표시·재생을 통과했다. 잎 장식 네발 친구는 분리 성분 28개(기대 16개)로 판독 거부됐다. Anna 제공자 검증과는 구분하며, 이번에는 검수·기록만 수행해 배포·심사 후보를 변경하지 않았다. [체형별 결과·원인·재생 자료](docs/HOME_BODY_REVIEW_20261016.md).

앱 **1.4.5 / ID 1417 / working revision 59**, 도구 **0.9.1 / Executa version 760**. 소스 **`848918751f6a524957f18997f4de0e6b9bad9d9b`**. 소유자 초안 `0.0.0-draft` 설치 성공, `dirty_vs_latest_cut=false`. 사용자 요청에 따라 심사 후보를 **1.0.0 → 1.4.5 / pending_review**로 교체했다. Anna 공개 출시는 하지 않았다.

- 기존 개인 시트의 좌우 보행 중 대표 머리가 반대 방향으로 바뀌는 문제를 보정했다. Codex 내장 imagegen 결과 중 머리 수가 줄어든 시안은 제외하고, 아홉 머리·다리 없는 몸·관·진주 장식과 좌우 대표 방향을 유지한 시트를 검수했다. 원본 초상화는 그대로 두고 이전 시트는 아트 인덱스의 별도 백업 항목에 보존했다. 개인 파일은 Git 제외 `.local/quality-review/`와 소유자 저장소에만 둔다.
- 공통 생성 명세는 좌우의 화면 기준, 보행·정지·눈 감기 동안 고정할 방향, 다중 머리의 수·배열·장식과 32px 가독성을 구체화한다. 다른 사용자의 기존 시트를 교체하지 않으며 생성 버튼·입장 시 생성·자동 유료 재시도는 추가하지 않았다.
- 로컬 **JS 89 / 브라우저 103 / strict** 통과. 넓은 몸·키 큰 몸·날개형·둥근 몸의 방향/보행 선택·접지·좌우 반전 회귀 검사를 추가했다. 실제 개인 시트는 16프레임·32/64px 비교·마당/실내·나무 앞뒤 가림을 확인했다. 실제 설치 홈에서 **4개 방향 행·4개 동작 열**을 모두 관찰했고 sprite=ready다. 설치 코드 3개 HTTP 200 / SHA-256이 소스와 일치한다.
- Windows/Linux 0.9.1은 이전 검증 패키지를 재사용했다. 클라우드 도구 **0.9.1 / loaded=true / running=true**, 설치 응답 `already_satisfied`. PC 로컬 실행은 이번에 확인하지 않았다. [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38849480005)와 [Anna Windows/Linux CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38849480039)의 UI·브라우저·저장/프로토콜·패키지 자체 검사 모두 성공했다.
- 게임·대화·이야기·성격 초안 저장 응답(값·ETag)과 도구 개인정보 inspect 응답은 작업 전후 동일하다. 아트는 대상 시트 항목과 이전 시트 백업만 변경하고 다른 항목은 동일하다. 공유 소개·스크린샷 6개·로고·지원 링크는 유지했다. 사용하지 않던 빈 cover_url만 플랫폼이 null에서 빈 문자열로 정규화했다.
- Git merge로 `release-web`에 통합, 웹 **0.4.2 / 소스 `339181ef8ce271b268f7881825ca004e9ec9284d`**. [Pages 검사·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38849826706)와 [웹 공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38849826764) 성공. 로컬 웹 홈/던전/그림/저장 통합 검사 통과. 실제 공개 URL에서 0.4.2와 로드된 공통 시트 모듈의 빌드 일치·1120/360px·저장 동일·AI 0회·페이지 오류 0을 확인했다. 사용자의 웹 저장소는 건드리지 않았다.
- 제한: 프롬프트는 생성물의 방향·외형을 보장하는 의미 검사기가 아니다. 소유자 시트는 대표 머리와 자세로 좌우를 구분하며 모든 보조 머리가 완전한 측면으로 정렬되는 것은 아니다. 다른 실제 체형의 생성 품질과 Anna 제공자의 참조 생성 성공은 별도 검증이 필요하다. 합성 체형 검사는 렌더러 검증이다. [배포 기록](releases/RELEASE_145.md) · [기존 검수와 보정 결과](docs/HOME_VISUAL_REVIEW_20261016.md).
