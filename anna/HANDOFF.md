# 1.4.3 · 이미지 변경 시 동작 준비, 홈·던전 공동 사용 · 2026-10-16

앱 **1.4.3 / ID 1413 / working revision 57**, 변경 없는 도구 **0.9.1 / Executa version 760**. 배포 소스 **`895ffa99dd573bc223f371fc4448a52c5a256273`**. 소유자 테스트 설치 `0.0.0-draft`, `dirty_vs_latest_cut=false`. 심사 후보 **1.0.0 / ID 1383 / pending_review** 유지.

- 수동 동작 생성·재생성 버튼을 제거했다. 새 친구 생성(랜덤 포함), 새 초상화·새 진화 그림 저장 시 현재 그림으로 동작을 이미지 AI 한 번에 준비한다. 성장 단계 숫자만 바뀔 때는 생성하지 않는다. 홈·던전 열기, 이동, 재입장, 저장 재시도에도 AI를 쓰지 않는다.
- 같은 원본의 요청 예약을 조건부 저장해 중복 저장·동시 창·응답 유실 후 AI 재요청을 억제한다. 실패해도 친구와 원본은 유지한다. 이미 받은 결과의 저장 재시도만 제공한다. 아바타 착용은 아직 없으며, 추후 최종 착용 그림은 동일한 `syncPortraitVisuals` 흐름을 사용한다.
- 홈과 던전은 같은 개인 스프라이트와 프레임 렌더러를 사용한다. 던전의 이동 방향에 따라 걷는 자세가 바뀌며 새 동작에는 초상화 회전·흔들기를 적용하지 않는다. 동작이 없는 기존 친구나 다운로드 실패는 그 친구의 초상화로 대체 표시한다.
- 로컬 **JS 89 / 브라우저 99 / strict** 통과. [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38833400645) Windows/Linux/Pyodide 성공. [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38833400650) Windows/Linux UI·브라우저·저장/프로토콜·패키지 자체 검사 성공. 도구 소스가 같아 앞서 검증·배포한 두 OS의 0.9.1 패키지를 유지했으며 새 도구 버전은 만들지 않았다.
- 실제 설치 앱 **Connected**, 오류 안내 없음. 생성 버튼 제거, 기존 소유자 홈 동작 ready, 지옥문 미리보기의 `sprite=home`을 확인하고 화면을 캡처했다. UI 코드 8개 HTTP 200 / 로컬 SHA-256 일치. 실제 이동은 소유자 이미지를 넣은 별도 테스트 화면에서 검증했다. 실제 탐험 입장·보상·AI 생성은 실행하지 않았다.
- 클라우드 도구 **0.9.1 / loaded=true / running=true**. 설치 응답 `already_satisfied`로 기존 실행 도구를 재사용했다. PC는 오프라인이므로 해당 PC 실행 상태는 확인하지 못했다.
- 게임·아트·대화·산책 이야기·성격 초안 **5종 값과 ETag 모두 배포 전후 동일**. 기존 심사·공유 소개·스크린샷 6개도 동일하다. 재심사나 공개 출시는 하지 않았다. [배포 기록](releases/RELEASE_143.md).
- 남은 제한: 실제 Anna 참조 이미지 생성은 계정 사용량 부족으로 미검증이다. 생성 실패는 자동으로 AI를 재호출하지 않으며 다음 새 그림에서 준비한다. 저장 전 결과는 페이지를 닫으면 유실될 수 있다. 외형·방향의 의미상 정확도, APS 최초 생성 경합과 아바타 착용 미구현은 [안내](docs/HOME_PIXEL_ART.md)를 따른다.

# 1.4.2 · 집과 마당, 개인 방향별 스프라이트 · 2026-10-16

앱 **1.4.2 / ID 1412 / working revision 56**, 도구 **0.9.1 / Executa version 760**. 앱·도구·미술 소스 **`4cc8f1d65ef0f39e3efa87c784829d8c79b93128`**, 이후 `a27773d`는 Pyodide 테스트의 파일 목록만 보완했다. 소유자 테스트 앱 설치 `0.0.0-draft`, `dirty_vs_latest_cut=false`. 심사 **1.0.0 / ID 1383 / pending_review** 유지.

- 승인된 시제품을 실제 홈에 연결했다. 넓은 탑다운 마당·집 외관·별도 실내, 방향별 16프레임·발밑 기준 이동·깊이 가림·자동 출입·카메라 추적·확대/축소·정지, 필요할 때 여는 상점이다. 기존 12종 가구·코인·소유·배치·되돌리기·성격에 따른 꾸미기는 유지한다.
- `움직이는 모습 만들기`를 명시적으로 누르면 현재 친구의 현재 성장 그림을 참조 이미지로 보내 생성한다. 저장된 친구 ID·단계·원본 경로가 모두 일치해야 표시하며 공통 예시로 대체하지 않는다. 홈 열기·구매·이동·재열기·저장 재시도에는 AI를 호출하지 않는다. 기존 던전용 무료 픽셀 변환과 별개다.
- 소유자 예시는 Anna 사용량 부족 때문에 내장 imagegen으로 원본을 참고해 별도 제작했다. 아홉 머리를 보정하고 16프레임을 확인한 용용이 파일을 소유자 앱 저장소에만 추가했다. 원본/기존 아트 항목·게임·대화·이야기·성격 초안은 보존했다. 게임 등 4종 값과 ETag도 같으며, 아트에는 개인 스프라이트 항목 하나만 추가됐다. 개인 파일은 Git/공용 번들에 포함하지 않는다.
- 검증: Python **223**, JS **87**, 브라우저 **96**, Anna 저장·프로토콜 **70**, strict 통과. 실제 소유자 이미지로 데스크톱·모바일을 렌더링하여 외부 AI 0회·가로 넘침 없음·로드 오류 없음을 확인했다. [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38830943645)는 Windows/Linux/Pyodide 성공. [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38830664499)는 Windows/Linux 테스트와 0.9.1 실행 패키지 빌드·자체 검사 성공. 두 CI 패키지를 함께 업로드했다.
- 실제 설치 UI Connected, 개인 스프라이트 ready, 집/마당 전환과 재열기를 확인했다. 홈 코드·미술 파일 9개가 HTTP 200이고 로컬 해시와 같다. 클라우드 실행 도구 **0.9.1 / loaded=true / running=true** 확인. PC 실행기는 오프라인이어서 새 Windows 패키지의 그 PC 실행 상태는 확인하지 못했다.
- 공유 소개·스크린샷 6개·심사 후보를 그대로 유지했다. 재심사·공개 출시는 하지 않았다. [배포 기록](releases/RELEASE_142.md) · [자산/생성 안내](docs/HOME_PIXEL_ART.md).
- 남은 제한: Anna 이미지 서비스의 실제 참조 생성은 계정 사용량 부족으로 미검증이며, 모의 제공자로 참조 전달·저장 복구·다른 친구/원본 배제 계약을 검사했다. AI의 의미상 외형·방향 일치는 사용자 확인이 필요하다. 저장 전 결과는 페이지를 닫으면 잃을 수 있다. 실내 배치 후보와 APS 최초 생성 경합은 기존 제약을 따른다. 웹 UI 이식과 새 홈의 던전 적용은 이번 범위가 아니다.
