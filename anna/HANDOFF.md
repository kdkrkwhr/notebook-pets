# 1.2.0 · 던전 아이템 수집과 보관함 · 2026-10-15

소스 후보 **1.2.0 / 도구 0.8.0**. **테스트 배포 대기 중이며 현재 설치 앱은 아직 1.1.2다.** Windows/Linux CI 패키지와 실제 설치 UI·실행 도구 확인이 필요하다. 심사 후보 **1.0.0 / ID 1383 / pending_review** 및 공유 소개는 보존한다.

- 지역별 마지막 수호자 승리에 미보유 일반 3종→희귀 1종을 순서대로 지급한다. 20종 수집, 지역별 완성 후 중복 없음. 기존 코인·산책·일일 규칙은 유지한다.
- 내 보관함, 도감 보유·미보유 필터, 카드·상세 보유 표시, 클리어 획득 아이템 이름을 연결했다. 공용 4종·상점·착용·새 AI 요청은 없다.
- 읽기만으로 기존 저장을 변경하거나 과거 클리어를 소급 지급하지 않는다. 아이템·코인·클리어·영수증을 함께 저장하고 응답 유실 재시도와 저장 실패를 검사한다.
- 로컬 JS **82/82**, 엔진 **207개(선택 검사 1개 skip)**, 저장·프로토콜 **66/66**, strict 통과. 브라우저 전체 **91/91**, 보관함·최종 획득 연결 추가 2개 검사도 통과했다.
- 원본 그림·게임·대화 데이터 보존, 두 OS 패키지와 실제 설치 검증은 배포 후 결과를 기록한다. [전체 기록](releases/RELEASE_120.md).

# 1.1.2 · 확장 지역 아이템 8종·도감 24종 · 2026-10-15

앱 **1.1.2 / ID 1394 / working revision 51**, 도구 **0.7.0 / Executa version 752**. 소스 **`e16c50bf84526597722bc507cb9953f68a142f8d`**를 푸시하고 불변 버전을 만들었다. 소유자 테스트 앱은 같은 내용의 `0.0.0-draft`로 설치됐으며 `dirty_vs_latest_cut=false`다. 심사 후보는 **1.0.0 / ID 1383 / pending_review** 그대로다.

- 침몰한 왕궁·잊혀진 태엽도시에 머리·목·등·주변 효과 아이템을 각각 4종 추가해 도감이 총 24종이 됐다. 산호 진주 왕관·작은 태엽 무리는 희귀 미리보기다. 한국어·영어 설명, 지역·부위 필터, 검색, 예정 획득 방법과 착용 기준을 연결했다.
- 투명 PNG 8개를 내장 이미지 도구로 개별 생성해 원본 그대로 포함했다. 도감 열람에는 AI 호출이 없다. 수집·구매·착용·실제 던전 보상은 변경하지 않았다. 한국어·영어 README에 실제 UI로 촬영한 전체 도감·상세·모바일 스크린샷 3장을 넣었다.
- 로컬 JS **81/81**, 브라우저 **90/90**, strict 통과. 도감 테스트는 새 지역 8종의 그림 디코딩·설명·필터와 AI/저장 변경 없음, 360px 한국어 화면을 확인한다. 문서 9개·로컬 링크 156개·이미지 11개 검증. [엔진 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38708748960) 성공, [Anna CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38708749027) Windows/Linux 모두 성공(저장·프로토콜·패키지 빌드 및 자체 실행 검사 포함).
