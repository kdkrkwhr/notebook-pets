# 1.4.6 · 최신 수정 묶음의 심사 후보 교체 · 2026-10-17

사용자가 최신 수정도 심사에 반영하도록 요청해 **1.4.6 / ID 1426 / working revision 64**를 만들고 후보를 **1.4.5 → 1.4.6 / pending_review**로 교체했다. 서버 재조회로 확인했으며 `dirty_vs_latest_cut=false`다. 소유자 초안 설치 성공·실패 Executa 0개. 게임 도구 **0.9.1 / Executa 760**은 그대로다. 공개 출시 명령은 실행하지 않았다.

- 기존 1.4.5 cut 뒤에 수정한 전투/던전 안내·가구 구매 확인창·정적 픽셀/동작 구분·실패 단계 진단·분리 부위 판독이 모두 포함됐다. UI 번들은 revision 63의 검증본과 동일하며 메타데이터만 1.4.6으로 올렸다.
- 기존 JS 91·브라우저 106·Windows/Linux/Pyodide CI·설치 모듈 및 실제 웹 검증을 재사용했다. 1.4.6 메타데이터의 strict 검증 통과. 저장 4종 값/ETag와 게임 inspect, 소개·스크린샷·로고·지원 링크 모두 동일하다.
- 웹은 0.5.0 기존 검증 배포를 유지하며, 이번 작업은 버전/심사 기록만 바꿨다. 원래 dora의 실패 원인과 유실된 생성 결과 복구는 여전히 미검증이다. [1.4.6 기록](releases/RELEASE_146.md).

# 1.4.5 후속 · 분리된 동작 부속 부위 판독 · 2026-10-17

스크린샷의 정적 미리보기 “Ready for dungeon exploration” 혼동은 이전 진단 수정에 포함돼 있다. 이번에는 별도로 재현 가능한 판독 오류를 수정했다. **dora의 당시 실패가 이 오류 때문인지는 원본 응답/요청 로그가 없어 확정하지 못하며, 과거 실패 결과를 복구했다고 주장하지 않는다.**

- 시트의 연결 성분을 곧바로 프레임 수로 취급해, 떨어진 꼬리 끝·장식이 있으면 정상 4×4도 거부하던 오류다. 16개 주요 몸체의 배치를 찾고, 행/열의 실제 빈 간격 안에서 가까운 작은 부속 부위만 하나의 후보에 귀속될 때 포함한다. 고정 사분면 절단·부위 삭제·이미지 보정 없이 원본 픽셀을 유지한다. 큰 부위·추가 큰 캐릭터·경계에 걸친/모호한 부위·잘림·겹침·누락·크기 불일치는 거부한다.
- 수정 전 실패하는 회귀를 확인하고, 분리 꼬리·불균등 간격 수용과 7종 잘못된 입력 거부를 검사했다. Anna와 웹의 생성→판독→저장 실패→저장만 재시도→홈/던전 재사용 시나리오에 분리된 꼬리 입력을 추가했다. AI 요청은 기존 한 번이며 재생성·자동 재요청 버튼은 추가하지 않았다.
- 이전 4종의 동일 PNG를 재생성 없이 다시 검사해 **4종 모두 16프레임 / sprite=ready / 네 방향·네 프레임 / 실내외 표시**를 확인했다. 기존 3종 회귀 없이 잎 장식 네발 친구의 28개 성분을 16개 프레임으로 묶는다. 홈 32px·던전 약 67px와 375px 화면을 확인했다. 검수 파일은 `.local/body-review-fixed/`에만 있다.
- Anna **1.4.5 소스 / working revision 63 / 소유자 초안 0.0.0-draft** 업로드·설치 성공. 소스 **`a489aa13f6839d2376392a080b6fdadb848a9e8a`**, `dirty_vs_latest_cut=true`. 실제 설치 화면 Connected·정적 미리보기 안내를 확인하고, 설치된 실제 모듈로 기존 실패 PNG가 16프레임으로 읽히는 것을 확인했다. 모듈 HTTP 200 / 원본 바이트 SHA-256 `0b9a8368e427eb595bdb34e27925abf30ee8c55a5dbf499c24ed488b7ae93ee3`이 로컬과 일치했다. 순수 함수 검수는 공책 밖에서 수행했고 사용자 아트에 테스트 시트를 연결하지 않았다.
- 설치 전후 앱 저장 4종의 값·ETag와 게임 inspect 응답 동일, 소개·스크린샷·로고·지원 링크·심사 후보도 정확히 같다. 실제 유료 AI 호출 0회다. 도구 **0.9.1 / Executa 760**은 변경·재게시하지 않았고 클라우드 loaded/running, 설치 `already_satisfied`를 확인했다. PC 로컬 실행은 이번 범위가 아니다.
- 검사: 로컬 **JS 91 / 브라우저 106 / strict**, 웹 홈/던전/그림/저장 통합 통과. [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38927806778)와 [Anna Windows/Linux CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38927806437)의 UI·브라우저·저장/프로토콜·패키지 검사 모두 성공했다.
- 공유 수정을 Git merge로 `release-web`에 통합했다. 웹 **0.5.0 유지**, 배포 소스 **`b81fa41f2780d1f31c0b5782d143ec2f6dbb62f2`**. [Pages 검사·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38928214360)와 [웹 공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38928214277) 성공. 실제 공개 URL에서 로드한 모듈과 빌드 일치, 기존 실패 PNG의 16프레임 판독, 1120/360px·저장 동일·외부 요청 0·페이지 오류 0을 확인했다. 격리 브라우저만 사용했다.
- **새 cut/심사 제출/공개 출시 없이 기존 심사 후보 1.4.5 / ID 1417 / pending_review를 유지했다. 이번 수정은 그 심사본에 포함되지 않는다.** 실제 Anna 제공자의 생성·과거 버려진 결과 복구·외형/방향의 의미적 정확도는 미검증이다. 큰 부위나 프레임 사이를 넘는 부위는 안전상 계속 거부할 수 있다. [배포 기록](releases/RELEASE_145.md) · [체형 검수 후속](docs/HOME_BODY_REVIEW_20261016.md).
