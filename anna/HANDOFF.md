# 1.0.0 심사 제출 · 소개글·스크린샷 갱신 · 2026-10-14

사용자 요청으로 심사 대상을 **0.8.1 → 1.0.0 / ID 1383**으로 교체했다. 이후 서버를 다시 조회해 **pending_review / review_candidate_version=1.0.0**을 확인했다. 승인·공개 전이며 `release`는 실행하지 않았다.

- 소개글: 던전 캐릭터 움직임, 아이템 도감 미리보기(친구를 만난 뒤 열림, 수집·착용은 이후 예정), "Updated in 1.0.0" 문단을 반영했다.
- 스크린샷: Anna 최대치인 **6장**으로 구성했다(7장 요청은 422로 거부되어 아무것도 바뀌지 않았다). 순서는 홈·타이틀·그림 편집·던전 미리보기·아이템 도감·첫 만남이다.
- 캡처 방식: 1.0.0 번들과 기록된 Mori 생성 결과로 캡처했으며, AI·실제 저장소 호출은 0회다.
- 캡처 스크립트 수정: 번들 폰트를 `font/woff2`로 제공한다. 지연 로딩 이미지 때문에 멈추던 대기를 보이는 이미지로 한정했다. 원본 참고 그림의 해시를 검사하고, 다시 그린 그림은 픽셀 비교(허용 2%, 실측 0.0%)로 확인한다.
- 서버 재조회에서 소개 필드 7종이 로컬과 일치했다. CDN 6장을 내려받아 순서를 육안으로 확인했다. [심사 기록](reviews/REVIEW_100.md).

# 1.0.0 · 던전 캐릭터 2.5D 연출 · 테스트 배포 완료 · 2026-10-14

사용자 요청으로 앱 버전을 1.x로 올렸다. 앱 **1.0.0 / ID 1383 / revision 48**, 실제 도구 **0.6.0 / Executa version 746 / loaded=true / running=true**(도구 변경 없음). 공개 출시가 아닌 소유자 테스트 배포다.

던전 캐릭터가 방향을 바꿀 때 뒤집히지 않고 카드 가장자리를 지나 180ms 동안 돈다. 걸음마다 눌림·뜀·앞기울기가 있다. 멀어지면 작게, 다가오면 크게 보이고, 월드 왼쪽에서 오는 단계 음영과 높이에 따른 그림자를 넣었다. 뒷모습이나 없는 부위를 새로 만들지 않으며, AI·새 그림·저장 변경은 없다.

검증 결과:
- JS 80·브라우저 89·strict 검사와 Windows/Linux CI가 통과했다.
- 실제 앱에서 두 모듈의 SHA-256 일치를 확인했다.
- 확인 시점에 열린 던전이 없었다. 그래서 설치된 모듈로 사용자 친구의 실제 픽셀 그림을 임시 오버레이에 그려 확인하고 오버레이를 제거했다.
- 저장값 5종과 ETag는 전후 동일하다. 0.8.1 심사와 소개글을 유지했다. [전체 배포 기록](releases/RELEASE_100.md).
