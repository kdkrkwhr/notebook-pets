# 1.4.4 · 내 공책의 일곱 가지 테마

배포 준비 중. Anna 소유자 테스트 앱과 공개 웹에 함께 반영하며, 기존 심사 후보 1.0.0과 공유 소개·스크린샷은 유지한다. 게임 도구는 0.9.1 그대로다.

- 상단 **◐ 테마**에서 기본 공책·고요한 밤·지옥문·얼음왕국·몽환의 숲·침몰한 왕궁·잊혀진 태엽도시를 선택한다. 선택 즉시 미리 보고 다음 실행에도 유지한다.
- 대화·돌봄·도감·홈 상점·타이틀 화면에 같은 색상을 적용한다. 캐릭터 그림과 홈·던전 캔버스는 원래 색을 유지한다.
- 한·영 표시, 키보드 선택, 작은 화면, 저장 불가 환경의 현재 세션 적용을 지원한다. 테마는 이 브라우저의 설정이며 기기·Anna·웹 간 동기화나 게임 백업 대상이 아니다.
- 테마 선택은 AI·게임 도구·계정 저장소를 호출하지 않는다. 게임 초기화는 테마를 유지하며, Anna의 전체 저장 데이터 삭제 성공 시에는 테마 설정도 지운다.

검증·배포 결과는 완료 후 기록한다.
