배포 완료: Anna 소유자 테스트 앱 **1.4.4 / ID 1416 / working revision 58**, 공개 웹 **0.4.1**. 기존 심사 후보 **1.0.0**과 공유 소개·스크린샷 6개는 유지했다. 게임 도구는 **0.9.1 / Executa version 760** 그대로다.

- 테마 선택은 AI·게임 도구·계정 저장소를 호출하지 않는다. 게임 초기화는 테마를 유지하며, Anna의 전체 저장 데이터 삭제 성공 시에는 테마 설정도 지운다.
