# 1.4.3 · 이미지 변경 시 동작 준비, 홈·던전 공동 사용

배포 준비: 앱 **1.4.3**, 변경 없는 게임 도구 **0.9.1**. 기존 심사 후보 **1.0.0**과 공유 소개·스크린샷은 유지한다. 실제 설치 결과는 배포 후 기록한다.

- 수동 동작 생성·다시 만들기를 제거했다. 새 친구 생성(랜덤 포함)과 새 초상화·새 진화 그림 저장 시 현재 그림을 참조해 이미지 AI 한 번으로 방향별 동작을 준비한다. 성장 단계 숫자만 바뀔 때는 호출하지 않는다.
- 같은 원본의 요청 예약을 저장해 중복 저장·동시 창·실패 후 다시 실행에서 AI 중복 호출을 막는다. 실패해도 친구와 원본 그림은 보존한다. 받은 결과의 저장 재시도만 남기며 AI를 사용하지 않는다.
- 홈과 던전이 같은 사용자별 동작 파일과 프레임 렌더러를 사용한다. 던전에서는 진행 방향에 맞춰 걷고, 이 동작에는 기존 초상화 회전·흔들기를 적용하지 않는다. 동작이 없는 기존 친구나 다운로드 실패 때만 해당 친구의 초상화로 표시한다. 탐험·재입장·이동은 AI를 사용하지 않는다.
- 생성 및 새 그림 화면과 한·영 안내에 추가 이미지 사용량을 알린다. 아바타 착용은 아직 없으며, 최종 착용 그림을 저장하는 기능이 생기면 같은 `syncPortraitVisuals` 흐름을 사용한다.
- 게임 규칙·보상·저장된 친구·기존 동작 파일은 변경하지 않는다. Python 및 실행 도구는 그대로다. 웹 브랜치는 이번 범위에 포함하지 않는다.

제한: 실제 Anna 참조 이미지 생성은 계정 사용량 부족으로 검증하지 못한다. 생성 실패를 AI로 자동 재시도하지 않으며 다음 새 그림에서 준비한다. 저장 전 결과는 페이지를 닫으면 유실될 수 있다. 의미상 외형·방향 보존과 APS 최초 생성 경합은 [기존 제한](../docs/HOME_PIXEL_ART.md)을 따른다.
