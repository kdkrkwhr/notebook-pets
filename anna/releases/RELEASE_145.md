# 1.4.5 · 방향별 동작 일관성 보정

좌우 보행 행의 방향이 뒤섞이는 문제를 줄이도록 스프라이트 생성 명세를 구체화했다. 왼쪽·오른쪽의 화면 기준, 정지·눈 감기까지 유지할 방향, 다중 머리의 수·배열·장식 보존과 32px 가독성을 명시한다. 생성 프롬프트만으로 의미상 정확성을 보장하지 않으므로 실제 결과의 시각 검수는 계속 필요하다.

소유자 개인 시트는 Codex 내장 imagegen으로 보정하고 16프레임과 실제 32px/64px 렌더링을 확인했다. 대표 머리의 좌우 방향을 보행 A·기본·보행 B·눈 감기 내내 유지하며 아홉 머리·다리 없는 몸·관과 진주 장식을 보존했다. 원본 초상화와 이전 시트는 보존했고, 개인 결과물은 공용 번들에 포함하지 않았다. 다른 사용자의 기존 시트를 일괄 교체하거나 재생성하지 않는다.

홈·던전의 방향/보행 프레임 선택과 접지·좌우 반전 여부를 4종 체형으로 검사하는 브라우저 회귀 검사를 추가했다. 구매·보기·이동·재입장·저장 재시도는 AI를 호출하지 않으며 생성·재생성 버튼이나 자동 재요청을 추가하지 않는다. 게임 도구는 변경 없는 0.9.1을 재사용한다.

배포 및 최종 심사 후보 교체 결과는 검증 완료 후 이 문서와 HANDOFF.md에 기록한다.
