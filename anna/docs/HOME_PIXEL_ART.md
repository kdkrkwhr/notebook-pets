# 집과 마당 · 픽셀 자산과 개인 스프라이트

1.4.2는 집 외관과 마당, 별도의 실내를 Canvas로 그린다. 지형·가구·친구는 각각 독립된 그림이며, 이동 경로는 Python 코어가 제공한다. 개인 초상화나 스프라이트를 공용 번들에 넣지 않는다.

## 공용 미술

- [objects.png](../../assets/home-v2/objects.png): 앞서 승인받은 시제품의 집·나무·덤불·벤치·책장·책상·잠자리·화분·러그 9개. 원본 PNG를 수정하지 않고 재사용했다.
- [extra.png](../../assets/home-v2/extra.png): 이번에 만든 램프·작은 탁자·방석·별 액자·커튼·찻잔 세트·바구니·우편함. 투명 배경 4열×2행, 따뜻한 나무와 세이지 그린, 기존 타일 세계와 같은 탑다운 시점·픽셀 외곽선을 제작 명세로 사용했다.
- [atlas.json](../../assets/home-v2/atlas.json): 각 오브젝트의 그림 영역. 원본을 자르거나 덮어쓰지 않고 런타임에서 필요한 영역만 그린다.
- 미술 제작 도구: Codex 내장 **imagegen**. Anna AI를 호출하지 않았다. 시제품 미술의 상세 프롬프트는 [기존 기록](../../prototypes/pixel-home/ART_PROMPTS.md)을 따른다.

## 사용자마다 자기 친구의 움직임

홈의 **움직이는 모습 만들기**를 명시적으로 선택하면 현재 친구의 현재 성장 단계 그림을 참조 이미지로 전달하여 동작 시트를 요청한다. 최초 캐릭터 생성·홈 열기·구매·꾸미기·이동·재열기 때 자동 생성하지 않는다. 기존 던전의 무료 픽셀 변환과는 별도 기능이며, 방향별 새 자세 생성에는 이미지 AI 1회가 필요하다.

정확한 서비스 프롬프트는 [HOME_SPRITE_PROMPT](../bundle/home-sprite.mjs)에 보관했다. 4행은 아래·왼쪽·오른쪽·위, 4열은 이동 A·기본·이동 B·눈 깜빡임이다. 참조 이미지의 종족·색·몸 형태·머리/팔다리 수·장식을 유지하도록 요청하고, 다리가 없는 친구에게 다리를 추가하지 않도록 명시한다. 채팅은 이 요청에 보내지 않는다.

`image.generate`의 `reference_image_urls`로 현재 저장 그림의 내려받기 주소를 전달한다. 번들 기본 그림은 사용자 앱 파일 저장소에 올린 참조 파일의 주소를 전달한다. 지원되지 않는 모델이나 요청 실패 시 참조 없는 다른 생성으로 자동 재시도하지 않는다.

결과는 16개의 분리된 실루엣, 행 배치, 크기, 잘림을 검사한다. AI의 셀 간격 오차로 꼬리가 잘리지 않도록 투명 영역으로 실제 프레임 경계를 찾는다. 외형·방향의 의미까지 자동 검증하지는 못하므로 완성된 화면에서 확인하고 필요하면 사용자가 다시 만들기를 선택한다.

## 저장·복구·개인 데이터

`notebuddy/art-v1`의 `pet_id/home-sprite-stage-N` 항목에 `format=home-sprite-v1`, 원본 경로, 친구 ID, 성장 단계, PNG 경로를 기록한다. 원본·친구·성장 단계가 달라지면 기존 스프라이트를 대신 표시하지 않는다. 같은 URL이어도 다른 친구의 캐시를 재사용하지 않는다.

이미지 응답을 받은 뒤 업로드·인덱스 저장에 실패하면 페이지가 열린 동안 결과를 보존한다. **저장 다시 시도**는 같은 결과를 저장하며 AI를 다시 호출하지 않는다. 페이지를 닫으면 저장 전 결과는 유실될 수 있다. 캐릭터 교체나 데이터 삭제 이후 늦게 도착한 결과는 연결하지 않는다. 새 파일은 기존 `portraits/` 정리·초기화·삭제 범위에 포함된다.

소유자의 AI 사용량 부족으로 이번 확인용 그림은 내장 imagegen으로 현재 원본을 참조해 별도 제작했다. 아홉 머리를 유지하도록 보정했으며, 파일과 사전·사후 검증 기록은 Git에서 제외된 `.local/home-pixel-owner/`에 둔다. 이 예시는 소유자의 Anna 앱 저장소에만 연결한다. 일반 사용자에게 공통 예시로 표시하지 않는다. 이는 Anna 이미지 제공자의 실제 생성 성공을 검증한 결과와 다르며, 해당 계정에서 실제 참조 이미지 생성은 사용량 확보 후 확인할 항목이다.
