# 집과 마당 · 픽셀 자산과 개인 스프라이트

1.4.2는 집 외관과 마당, 별도의 실내를 Canvas로 그린다. 지형·가구·친구는 각각 독립된 그림이며, 이동 경로는 Python 코어가 제공한다. 개인 초상화나 스프라이트를 공용 번들에 넣지 않는다.

## 공용 미술

- [objects.png](../../assets/home-v2/objects.png): 앞서 승인받은 시제품의 집·나무·덤불·벤치·책장·책상·잠자리·화분·러그 9개. 원본 PNG를 수정하지 않고 재사용했다.
- [extra.png](../../assets/home-v2/extra.png): 이번에 만든 램프·작은 탁자·방석·별 액자·커튼·찻잔 세트·바구니·우편함. 투명 배경 4열×2행, 따뜻한 나무와 세이지 그린, 기존 타일 세계와 같은 탑다운 시점·픽셀 외곽선을 제작 명세로 사용했다.
- [atlas.json](../../assets/home-v2/atlas.json): 각 오브젝트의 그림 영역. 원본을 자르거나 덮어쓰지 않고 런타임에서 필요한 영역만 그린다.
- 미술 제작 도구: Codex 내장 **imagegen**. Anna AI를 호출하지 않았다. 시제품 미술의 상세 프롬프트는 [기존 기록](../../prototypes/pixel-home/ART_PROMPTS.md)을 따른다.

## 사용자마다 자기 친구의 움직임

1.4.8부터 새 친구·새 초상화 저장 직후에는 무료 픽셀 미리보기만 준비한다. 첫 마이홈에서 AI 이미지 1회로 방향별 동작을 만들거나 무료 기본 이미지를 선택한다. 홈·던전 열기, 구매, 이동, 재열기에는 AI를 요청하지 않는다. 이전 참조 이미지 요청 실패로 기본 이미지가 설정된 경우 수정된 방식의 첫 선택을 다시 제공하지만, 선택 전에는 AI를 요청하지 않는다.

홈과 던전이 같은 개인 파일과 `drawHomeSprite` 프레임 렌더러를 사용한다. 던전은 실제 이동 방향에 맞는 행과 걷기 프레임을 선택하며 초상화 흔들기·카드 회전을 적용하지 않는다. 해당 동작이 없거나 읽지 못한 기존 친구만 자신의 현재 초상화를 대체 표시한다. 다른 친구의 동작은 재사용하지 않는다.

정확한 서비스 프롬프트는 [HOME_SPRITE_PROMPT](../bundle/home-sprite.mjs)에 보관했다. 4행은 아래·왼쪽·오른쪽·위, 4열은 이동 A·기본·이동 B·눈 깜빡임이다. 참조 이미지의 종족·색·몸 형태·머리/팔다리 수·장식을 유지하도록 요청하고, 다리가 없는 친구에게 다리를 추가하지 않도록 명시한다. 채팅은 이 요청에 보내지 않는다.

2026-10-18 실제 Anna 비교 시험에서 참조 URL·data URL·`image.edit`는 각각 HTTP 502를 반환했지만, 기존 외형 설명을 넣은 참조 없는 `image.generate`는 성공했다. 따라서 현재는 저장된 원본 분석 설명 → 저장 성격의 외형 설명 → 게임 이미지 프롬프트 순서로 이미 있는 텍스트를 재사용한다. 이미지 1회만 요청하며 새 이미지 분석이나 자동 대체 재요청은 하지 않는다. 현재 성장 단계를 포함하고, 채팅이나 참조 이미지 URL은 보내지 않는다. 픽셀 모습은 초상화와 세부 표현이 달라질 수 있다. [실제 시험 기록](HOME_IMAGE_TEST_20261018.md).

결과는 16개 주요 몸체의 행 배치, 크기, 잘림을 검사한다. 2026-10-17 수정부터 작고 가까운 꼬리 끝·장식이 몸통과 떨어져 있어도 실제 행/열 간격 안에서 하나의 몸체에만 귀속되면 같은 프레임에 포함한다. 각 부위는 몸체 면적의 20% 이하·합계 30% 이하이고 몸체 짧은 변의 18% 이내 거리여야 한다. 모호한 경계·큰 부위·겹침·잘림은 계속 거부한다. 고정된 사분면으로 자르지 않아 불균등 간격도 보존한다. 외형·방향의 의미까지 자동 검증하지는 못하며, 과거 버려진 생성 결과가 자동 복구되는 것은 아니다. 실패한 요청은 자동 재시도하지 않고 다음 새 그림 저장 때 새 동작을 준비한다.

## 저장·복구·개인 데이터

`notebuddy/art-v1`의 `pet_id/home-sprite-stage-N` 항목에 `format=home-sprite-v1`, 원본 경로, 친구 ID, 성장 단계, PNG 경로를 기록한다. 원본·친구·성장 단계가 달라지면 기존 스프라이트를 대신 표시하지 않는다. 같은 URL이어도 다른 친구의 캐시를 재사용하지 않는다.

유료 호출 전에 `pet_id/home-sprite-request-stage-N`에 원본 경로와 참조 파일 경로를 조건부 저장한다. 같은 원본의 중복 저장·두 창의 경쟁·응답 유실 후 재실행이 추가 AI 호출을 만들지 않게 한다. 최초 저장 행의 생성 경합은 기존 APS 제약을 따른다.

이미지 응답을 받은 뒤 업로드·인덱스 저장에 실패하면 페이지가 열린 동안 결과를 보존한다. **동작 저장 다시 시도**는 같은 결과를 저장하며 AI를 다시 호출하지 않는다. 페이지를 닫으면 저장 전 결과는 유실될 수 있다. 캐릭터 교체나 데이터 삭제 이후 늦게 도착한 결과는 연결하지 않는다. 새 파일은 기존 `portraits/` 초기화·데이터 삭제 범위에 포함된다.

소유자의 AI 사용량 부족으로 이번 확인용 그림은 내장 imagegen으로 현재 원본을 참조해 별도 제작했다. 아홉 머리를 유지하도록 보정했으며, 파일과 사전·사후 검증 기록은 Git에서 제외된 `.local/home-pixel-owner/`에 둔다. 이 예시는 소유자의 Anna 앱 저장소에만 연결한다. 일반 사용자에게 공통 예시로 표시하지 않는다. 이는 Anna 이미지 제공자의 실제 생성 성공을 검증한 결과와 다르며, 해당 계정에서 실제 참조 이미지 생성은 사용량 확보 후 확인할 항목이다.
