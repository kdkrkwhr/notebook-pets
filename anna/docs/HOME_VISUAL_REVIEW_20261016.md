## 심사 교체를 막는 문제

좌·우 행의 실루엣과 얼굴 방향이 충분히 구별되지 않는다. 같은 행에도 정면과 서로 다른 방향을 보는 자세가 섞여 있고, 오른쪽 기본 자세는 오른쪽 이동을 명확하게 표현하지 못한다. 실제 표시 크기에서도 좌우 전환과 보행 주기를 읽기 어렵다. 프레임 개수·배열·잘림 검사를 통과해도 방향의 의미까지 올바르다는 뜻은 아니다.

원본의 목걸이 같은 작은 장식도 시트에서 명확히 재현되지 않는다. 작은 표시 크기의 세부 생략과 별개로, 좌우 방향 일관성을 우선 해결해야 한다. 기존 시트를 좌우 반전하거나 행만 바꾸면 모든 프레임이 해결된다고 판단하지 않는다.
