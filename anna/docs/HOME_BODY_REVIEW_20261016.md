# 체형별 실제 생성 시트 검수 · 2026-10-16

대상은 Anna 1.4.5의 `HOME_SPRITE_PROMPT`와 `readHomeSprite`·홈/던전 공유 렌더러다. **대표 4종 중 3종은 판독·표시와 시각 검수를 통과했고, 잎 장식 네발 친구는 판독 거부 사례를 확인했다. 모든 체형 검증 완료로 판단하지 않는다.**

## 방법과 범위

기본 제공 그림 4종을 각각 참조 이미지로 넣어 Codex 내장 imagegen으로 시트를 한 번씩 생성했다. 체형별 프롬프트 보정이나 재생성 없이 앱의 동일 명세를 사용하고 투명 배경을 요청했다. 이는 실제 생성된 래스터 시트의 검수이며 합성 도형 검사가 아니다. **Anna의 `image.generate` 제공자 성공·동일 품질을 검증한 것은 아니다.** Anna 사용량이나 사용자 API 키는 사용하지 않았다.

원본·생성 시트·판독 지표·화면·재생 자료는 Git 제외 경로 `.local/body-review/`에 보관한다. 공용 번들이나 개인 저장소에는 연결하지 않았다. 앱·도구·웹 버전, 배포 및 현재 심사 후보 1.4.5는 변경하지 않았다.

## 판독 거부 원인

네발 친구 시트의 동일 연결 성분 검사에서 면적 기준을 넘는 성분이 **28개** 검출됐다. 몸통에 해당하는 큰 성분 외에 작은 성분 12개가 추가된다. 꼬리 끝과 장식처럼 의미상 캐릭터에 속하는 부위가 몸통과 떨어진 픽셀 덩어리로 그려진 경우다. 진단 시 오류 메시지에 성분 사각형만 추가로 노출했고 판독 조건은 바꾸지 않았다.

현재 판독기는 연결 성분 16개를 요구하므로 이 결과를 거부한다. 따라서 ‘육안으로 16칸이 있으면 반드시 수용된다’고 볼 수 없다. 이 사례를 잡음으로 간주해 작은 성분을 일괄 삭제하거나, 셀 경계로 무조건 잘라 수용하는 방식은 검수하지 않았다. 후속 수정에서는 같은 셀의 부속 부위를 안전하게 묶을 수 있는지와 이웃 셀 침범·잘림·실제 추가 캐릭터의 거부를 함께 검증해야 한다. 이번 작업에서 판독기 코드는 변경하지 않았다.

## 표시·재생 검증

- 수용된 3종은 실제 `readHomeSprite`가 반환한 16개 경계 사각형으로 표시했다. 네 방향 각각 보행 A/B의 정규화 실루엣이 다르며 단일 그림을 통째로 옮긴 결과만은 아니다. 이 수치 자체가 자연스러움을 보장하지는 않으므로 원본과 비교 화면도 직접 확인했다.
- 홈 32px와 실제 던전 경로의 약 67px(`scale=2.1`)에서 프레임별 표시를 확인했다. 표시된 샘플에서 날개·머리깃·발이 잘리지 않고 몸 하단이 기준선에 유지된다. 던전의 정지는 기본 프레임을 사용하며 홈 눈 깜빡임과 동일하지 않다.
- 실제 홈 장면에 3종을 각각 로드해 `sprite=ready`, 마당·실내와 375px 폭 화면을 확인했다. 같은 Python 월드와 이동 제어기로 400초 분량을 계산해 네 방향·네 프레임·실내외 전환을 확인했다. 이는 로컬 격리 장면이며 사용자 게임을 움직이거나 보상을 받지 않는다.
- 별도 재생 자료는 실제 공유 렌더러 함수의 복사본과 판독된 경계를 사용한다. 3종 모두 재생 중 서로 다른 그림 3개 이상을 확인했고 페이지 오류 0·외부 요청 0이었다. 좌우 방향 고정·걷기/정지·일시 정지로 직접 비교할 수 있다.

## 확인 자료

- `.local/body-review/preview.html`: 외부 서버 없이 여는 독립 재생 화면. 수용된 3종만 재생하고 거부된 시트는 원본 확인만 제공한다.
- `.local/body-review/*-contact.png`: 홈·던전 크기의 방향/프레임 비교.
- `.local/body-review/*-yard.png`, `*-inside.png`, `*-mobile.png`: 실제 홈 렌더러 화면.
- `.local/body-review/metrics.json`: 3종 수용, 1종 거부와 성분 경계·프레임 정보.
- `.local/body-review/PROMPT.md`: 사용한 정확한 생성 명세와 도구.

각 체형 한 장의 탐색적 검수이므로 성공률이나 전체 사용자 결과로 일반화하지 않는다. 용용이의 기존 다중 머리 보정과 이번 단일 머리 3종 수용 결과를 합쳐도, 모든 체형·성장 단계·제공자의 생성 품질을 보장할 수 없다.
