# Furniture-aware home life

The companion can pause beside its placed resting nest, little bookcase and leafy plant. Current personality affects visit order and time spent there. A short localized caption describes resting, looking through books or watching the plant.

The existing Python home geometry chooses reachable routes and facing. The browser only follows those routes and displays the companion's existing frames. Furniture remaining in storage or without a reachable interaction position is not visited. The default portrait-derived appearance keeps its existing image; no directional or new action pose is fabricated.

Watching, movement, pauses, reopening and these activity captions use no AI and write no game progress, rewards or layout. Furniture placement still happens only through the existing explicit Decorate request. Furniture transport suppresses leisure captions, and pause/reduced-motion behavior remains available.

This first bundle covers the three indoor objects. It does not simulate offline activity, add new furniture, auto-decorate or generate action sprites. Current deployment and validation evidence belongs in [HANDOFF](../HANDOFF.md).
