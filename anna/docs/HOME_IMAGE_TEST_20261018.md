# 마이홈 실제 Anna 이미지 비교 시험 · 2026-10-18

사용자가 Anna 토큰을 사용해 결함을 해결하도록 명시적으로 요청했다. 격리 개발 앱 notebuddy-dev에서 현재 소유자의 저장 초상화를 사용했다. 새 초상화·텍스트 생성 요청은 하지 않았다.

| 요청 | 결과 |
| --- | --- |
| 기존 image.generate + 참조 파일 URL | 약 2초, HTTP 502 / Cloudflare Bad gateway |
| image.generate + 이미지 data URL 참조 | 약 3초, HTTP 502 |
| 저장 외형 설명 기반 image.generate, 참조 이미지 없음 | 약 21초, openai/gpt-image-2, PNG 1024×1024 성공 |
| 문서화된 image.edit + 현재 초상화 | 약 3초, HTTP 502 |

총 이미지 API 시도 **4회**, 성공 결과 **1장**, 별도 텍스트·분석·초상화 생성 **0회**. 실패 요청의 실제 과금 여부는 응답으로 확인하지 못했다. 자동 재시도 루프는 없으며 각 비교를 한 번씩 수행했다. image.edit 검증용 임시 권한은 제거했고 제품 권한은 그대로다. 연속 호출 금지 정책을 확인한 것은 아니며, 재현된 참조 처리 경로 문제를 우회한다.

받은 원본은 비공개 로컬에 먼저 보관했다. 제품 readHomeSprite로 16프레임 판독을 통과했고 아래·왼쪽·오른쪽·뒤 행을 육안 확인했다. 저장된 원본 외형 설명을 사용하므로 초상화와 표정·스타일 차이는 남는다. 이를 초상화와 픽셀 모습의 완벽한 일치로 주장하지 않는다.

현재 친구·성장 단계·원본 그림·분석 설명이 바뀌지 않았음을 재확인한 후 해당 사용자 파일 저장소에 결과를 업로드하고 ART ETag 조건부 쓰기로 홈 시트와 요청 기록만 복구했다. 원본·초상화·대화·게임 보상은 수정하지 않았다. 복구는 이미지 추가 호출 **0회**. 실제 설치 마이홈에서 directional/ready, 빈 이미지 경고 숨김, 실내 이동 중 캐릭터 표시를 확인했다. 개인 이미지와 서명 URL은 Git/공용 번들에 넣지 않았다.
