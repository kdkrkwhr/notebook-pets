# Notebuddy 다음 개발 계획

2026-10-15 기준. 업데이트 **1.2.0**, 도구 **0.8.0**, 스토어 심사 후보 **1.0.0**이다. 다섯 던전과 24종 아이템 미리보기 도감은 구현·테스트 배포를 마쳤다. 현재 수치·제약은 [던전](DUNGEONS.md), [아이템](ITEMS.md), 실제 설치 근거는 [최신 인계](../HANDOFF.md)를 따른다. 아래 콘셉트는 구현 완료 항목과 후속 계획을 구분해 읽는다.

## 현재 작업과 개발 순서

1. 사진 선택 → 분석 → 생성 → 저장 → 재접속과 모바일 파일 선택의 실사용 검증을 이어간다. 0.3.5 당시의 미검증 범위는 [기록](../releases/RELEASE_035.md)에 남아 있으며 후속 설치만으로 완료 처리하지 않는다.
2. 다섯 던전의 캐릭터별 시각 품질과 밸런스를 확인한다. 침몰한 왕궁·잊혀진 태엽도시의 카드·보스 아트도 배포됐다.
3. 지역 아이템 획득·보관함은 1.2.0에서 연결했다. 공용 4종의 획득 방법, 코인 상점과 착용·해제가 다음 작업이다.
4. 이미지 편집 API 지원과 원본 유지 품질을 검증한 뒤, 사용자가 명시적으로 요청할 때 착용 모습을 AI 캐릭터 이미지에 반영한다. 부위별 착용 가능성은 [아이템 계획](ITEMS.md)을 따른다.
5. 이후 공중성·도서관·사막을 순차 확장한다. 신규 지역·가격·보상 수치는 미확정이다.

## 초기 던전 3종

세 지역은 비슷한 난이도와 기본 보상으로 시작한다. 이후 각 지역의 심층을 추가할 수 있다. 종족이 고정되는 게임이므로 모든 조합이 도전할 수 있으며, 특정 종족·속성만 입장하도록 제한하지 않는다.

| 던전 | 콘셉트와 보스 | 유리한 속성 후보 | 지역 적응 종족 후보 | 향후 아바타 예시 |
| --- | --- | --- | --- | --- |
| 지옥문 | 용암 다리와 봉인된 문 / 잿불의 문지기 | 물·땅·빛 | 용족·괴수족·유령족 | 잿불 뿔, 용암 망토 |
| 얼음왕국 | 눈보라 속 얼어붙은 성 / 서리 왕관의 수호자 | 번개·자연 | 포유류족·조류족·기계족 | 서리 왕관, 눈꽃 목도리 |
| 몽환의 숲 | 길이 바뀌는 숲과 빛나는 버섯 / 꿈을 먹는 사슴 | 불·바람·어둠 | 식물족·요정족·파충류족 | 나비 날개, 달빛 화관 |

종족 9종과 속성 8종 모두 활약할 지역이 있도록 한 배분 초안이다. 속성의 유리함은 기존 전투 상성표와 실제 등장 적의 구성을 통해 구현한다. 종족은 해당 지역에서만 작은 적응 보너스를 받는다. 보너스 종류·수치와 승률은 아직 확정하지 않았다.

현재 속성에는 얼음이 없다. 얼음왕국은 지역 테마이며, 물 속성 적에 대한 번개·자연의 기존 상성을 활용한다. 불 속성이 빙벽을 녹여 지름길을 여는 효과는 별도 탐험 이벤트의 확장 후보다. 지역 환경 효과와 전투 상성을 혼동하지 않도록 표시한다.

## 첫 구현 범위

- 기존 산책 중 던전을 발견하고, 발견한 던전은 발견 시점부터 24시간 유지하며 입장 카운트다운을 표시한다.
- 산책 포인트 1개로 입장하여 픽셀 맵에서 캐릭터가 자동으로 이동하고, 짧은 탐험 사건을 거쳐 보스전 1회를 진행한다. 기존 전투 계산을 재사용한다.
- 실패해도 던전은 남아 있으며 포인트가 있으면 재도전할 수 있다.
- 던전별 하루 첫 클리어에 코인을 지급하고, 세 지역의 기본 보상은 동일하게 시작한다.
- 입장 전에 주요 적 속성, 내 캐릭터의 지역 보너스, 입장 비용과 보상 수령 여부를 보여 준다.
- 승패·포인트 소비·코인 지급은 게임 규칙이 결정한다. 응답 재시도나 재접속으로 소비·보상이 중복되지 않게 기존 요청 영수증 흐름에 연결한다.

현재 0.4.2 후보는 진행 중인 던전이 없을 때만 매 산책 25%(첫 발견·누적 보장 없음), 종족 능력치 10% 적응, 지역별 당일 첫 승리 10코인을 사용한다. 발견한 던전만 보여 주고 탐험창은 앱 화면을 거의 채운다. 일반 배틀 제한·기록과 분리하고, 결과를 입장 시 저장하므로 자정을 넘긴 연출·재생은 원래 결과를 유지한다. 플레이테스트 후 수치를 조정하며 상점 가격은 아직 정하지 않았다.

산책 충전은 현재 코드상 **5분마다 1개, 최대 5개**다. 이전 대화에서 언급한 1시간과 차이가 있으므로 던전 경제를 조정할 때 기준을 확인한다. 이 계획 기록만으로 충전 주기를 변경하지 않는다.

## 픽셀 자동 탐험 · 추가 방향

사용자는 던전 탐사를 **픽셀 그래픽 + 캐릭터 자동 이동**으로 표현하기를 요청했다. 기존 단순 지도를 확인한 뒤 사용자는 비스듬히 위에서 보는 시점, 방·복도·적, 캐릭터를 따라가는 카메라를 선택했다. 0.4.2는 이 방향으로 세 환경 배경과 보스 자세·전투 효과를 실제 렌더러에 연결했다. [현재 구현](DUNGEONS.md), [아트 기록](../../assets/dungeons-v2/README.md)을 따른다. 아래 상세는 확장 방향이다.

2026-10-13 Codex 내장 이미지 생성 도구로 [초기 3종 비교 시안](../../assets/dungeons/concepts/initial-three-v1.png)을 제작했다. [생성 프롬프트](../../assets/dungeons/concepts/initial-three-v1.prompt.txt)도 함께 보관한다. 정적 콘셉트 이미지이며 Anna 앱 실행 화면·완성된 타일셋·걷기 스프라이트가 아니다. 공통으로 보이는 작은 캐릭터는 임시 샘플이다.

- 기존 육성 화면의 캐릭터 초상화를 유지하고 던전 안에서는 작은 픽셀 스프라이트로 표현한다.
- 입장하면 정해진 경로를 자동으로 걷고, 발견·보물·보스 장면을 보여 준다. 이동 조작은 요구하지 않는다. 경로 선택 등의 사용자 개입은 후속 후보다.
- 자동 이동은 우선 **앱을 열어 둔 동안의 탐험 연출**로 설계한다. 백그라운드·오프라인 자동 파밍을 뜻하지 않는다.
- 이동 애니메이션의 프레임이나 재생 속도로 보상을 결정하지 않는다. 게임 규칙의 저장된 결과와 진행 상태를 표시하며, 창을 다시 열거나 연출을 건너뛰어도 재입장 비용·보상이 중복되지 않게 한다.
- 시각 초안은 32픽셀 타일, 작은 걷기 스프라이트, 선명한 픽셀 경계와 던전별 제한된 색상을 기준으로 잡는다. 실제 타일 크기와 프레임 수는 모바일 화면 검증 후 정한다.
- 필요한 이미지: 지역별 바닥·벽·장애물 타일, 입구·출구, 장식·보물상자, 일반 몬스터·보스, 플레이어 이동 스프라이트, 전투·보상 효과와 아이콘.
- 컨셉 시안과 실제 게임 자산을 구분한다. 이미지 생성 후 실제 자산에는 타일 연결, 투명 배경, 프레임 정렬·방향별 일관성 검수가 필요하다. 사용자별 캐릭터의 특징을 픽셀 스프라이트에 반영하는 경로도 별도 검증한다.
- 던전 지도·이동 프레임을 매 탐험마다 AI로 새로 만들지 않는다. 2026-10-13 사용자가 선택한 1차 방식은 완성된 초상화를 기기에서 64×64 픽셀 PNG로 변환해 함께 저장하는 것이다. 추가 AI 사용량 없이 최초 생성·새 그림 저장 때 준비하며 기존 친구에게도 준비 버튼을 제공한다. 방향별 새 걷기 포즈는 후속이다.

## 아바타 연결

- 코인은 꾸미기용이며 초기 아바타에는 공격력·방어력·HP 보너스를 주지 않는다.
- 초기 상점은 약 5종으로 시작한다. 구매한 아이템을 사용자별 보관함에 저장하고 구매·착용·해제를 구분한다.
- 착용 조합을 바꾸는 것만으로 AI를 호출하지 않는다. 사용자가 ‘새 모습 만들기’를 요청할 때 생성한다.
- 원본 캐릭터의 실루엣·팔다리·얼굴·색·무늬를 우선하고 현재 성장 단계, 아바타 순으로 반영한다.
- 2026-10-12 Anna 참조 이미지 편집 테스트는 제공자 오류로 실패했다. 특징 분석 후 새로 생성하는 현재 흐름과 직접 이미지 편집의 지원 여부는 별개다. 원본을 유지하는 아바타 편집은 지원 경로 재검증과 시각 검토가 필요하다.
- 2026-10-14 확인: [이미지 입력 답변](https://forum.anna.partners/t/developer-feedback-image-inputs-to-llm-complete-may-not-be-reaching-the-model-and-the-documentation-is-less-explicit-than-for-agent-session/322/2)은 `llm.complete` 등의 이미지 블록 누락과 host `1.1.0-beta.169` 수정 안내다. 현재 `checkArtwork`의 이미지 블록 형식은 안내와 일치한다. `image.edit`의 제공자 경로가 고쳐졌다는 근거는 아니며, [별도 편집 오류 문의](https://forum.anna.partners/t/image-edit-fails-with-provider-errors-readerror-and-fal-ai-image-to-image-404/400)에는 확인한 시점에 답변이 없다. 이번 확인에서는 추가 유료 편집 요청을 하지 않았다.

던전 기획의 최초 원본은 사용자가 제공한 `DUNGEON_AVATAR_SPEC.md`다. 기존 예시 던전 3종을 이번에 합의한 지옥문·얼음왕국·몽환의 숲으로 대체하고, 이 문서를 현재 콘셉트와 순서의 기준으로 사용한다.
