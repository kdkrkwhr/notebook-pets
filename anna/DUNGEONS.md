# Pixel dungeon preview · 0.4.0 / tool 0.2.0

2026-10-13 구현 후보. 심사 중인 0.3.4와 설치된 0.3.5를 변경했다는 뜻이 아니다. 실제 Anna 배포 및 계정 검증은 별도로 기록한다.

## 캐릭터 픽셀 변환

사용자가 선택한 방식은 **완성된 캐릭터 그림의 로컬 변환**이다. 새 AI 픽셀 그림을 요청하지 않는다. 최초 랜덤 생성은 기본 그림에서, 그림·사진 생성은 저장된 최종 초상화에서 변환한다. 새 성장 그림을 저장하면 해당 단계의 픽셀 버전도 갱신한다. 기존 캐릭터에는 「픽셀 캐릭터 준비하기」를 제공한다.

- 64×64 PNG, 4픽셀 여백, 원본 비율 유지. 외곽과 연결된 거의 흰 배경을 지우고 색을 간소화한다. 테두리 안쪽의 흰 눈·무늬는 유지한다.
- 원본 그림은 수정하지 않는다. 복잡한 배경과 경계가 흐린 흰 캐릭터는 별도 시각 검수가 필요하다. 새 몸·다리나 방향별 포즈를 만들지 않는다.
- `notebuddy/art-v1`에 `<pet_id>/pixel-stage-<stage>`를 저장한다. 파일은 `portraits/<pet_id>/pixel-<uuid>.png`이며 원본 경로와 변환 버전을 함께 기록한다.
- 캐릭터·성장 단계·원본 그림이 바뀌면 이전 픽셀 이미지를 현재 버전으로 사용하지 않는다. 업로드 실패 시 같은 창에서 저장을 재시도하고, 재접속 후에도 원본으로 무료 재변환할 수 있다.
- 픽셀 준비 실패가 캐릭터 생성이나 원본 저장을 취소하지 않는다. 초기화·삭제·미사용 그림 정리는 기존 초상화와 같은 범위를 사용한다.

## 첫 탐험 규칙

| 항목 | 현재 구현값 |
| --- | --- |
| 지역 | 지옥문, 얼음왕국, 몽환의 숲 |
| 발견 | 매일 첫 성공한 산책은 1종 보장. 이후 25%, 3번째 산책까지 다음 미발견 지역 1종 보장 |
| 입장 | 발견한 지역, 산책 횟수 1개. 대기 중인 일반 조우를 먼저 끝낸다 |
| 충전 | 기존 5분마다 1개, 최대 5개 유지. 이전 대화의 1시간으로 임의 변경하지 않음 |
| 전투 | 같은 레벨·기본 능력치의 보스 1회. 기존 전투 판정 재사용 |
| 지역 적응 | 해당 종족의 체력·공격·방어 10% 정수 반올림, 각 최소 +1. 해당 전투에만 적용 |
| 보상 | 지역별 당일 첫 승리 10코인, 하루 총 30코인. 승리한 지역은 다음 날 재발견 후 입장 |
| 실패·무승부 | 보상 0, 당일 재도전 가능. 재도전에도 횟수 1개 사용 |
| 일반 배틀과 관계 | 일반 배틀 횟수·승패 기록·퀘스트·경험치·사료와 별개 |
| 날짜 | 한국 시간 자정에 발견·클리어 상태 초기화. 코인과 마지막 탐험 기록 보존 |

지옥문 적응 종족은 용·괴수·유령, 얼음왕국은 포유류·조류·기계, 몽환의 숲은 식물·요정·파충류다. 종족 제한 없이 모두 입장할 수 있다. 보스 속성은 지옥문 불·번개·어둠, 얼음왕국 물, 몽환의 숲 자연·땅·빛 중 날짜로 결정되며 같은 날 재시도로 바뀌지 않는다. 입장 전 실제 보스 속성, 자신의 공격 배율과 적응 보너스를 표시한다. 기존 상성표를 변경하지 않았다. 수치와 승률은 첫 플레이테스트용이며 최종 밸런스 확정은 아니다.

## 결과 저장과 화면

입장 요청 하나로 전투 결과, 횟수 차감, 코인, 클리어, 마지막 탐험과 영수증을 함께 저장한다. 저장에 실패하면 성공으로 응답하지 않는다. 앱은 이미 저장된 결과를 탑다운 픽셀 지도 위에서 자동 이동과 체력바로 재생한다. 3배속, 건너뛰기, 닫기, 재접속 후 마지막 탐험 다시 보기는 게임 행동이나 AI를 호출하지 않는다. 자정을 넘어 재생해도 입장 요청이 처리된 날짜의 결과를 유지한다. 백그라운드 자동 사냥은 없다.

지도는 공통 타일 규칙에 용암·얼음 결정·빛나는 버섯과 지역별 보스 표시를 조합한 코드 기반 첫 화면이다. 앞서 만든 컨셉 이미지와 동일한 완성 그래픽이 아니다. 캐릭터는 저장된 픽셀 한 장의 위치 이동·상하 움직임으로 표현하며 방향별 걷기 스프라이트는 후속이다. 길가 상자는 연출이며 별도 보상을 지급하지 않는다. 동작 줄이기 설정에서는 바로 결과를 표시한다.

## 후속 범위

전용 픽셀 타일·보스·걷기 프레임 아트, 사진·흰 캐릭터의 시각 품질 개선, 전투 연출, 난이도 플레이테스트, 코인 상점·아바타 착용, 추가 던전은 후속이다. 현재 코인은 누적만 가능하다. 이 후보는 공개나 심사 재제출 없이 테스트할 수 있도록 기존 제출 버전과 구분한다.

저장소의 동시 최초 생성 및 다른 창에서 진행 중인 초기화·파일 정리의 기존 플랫폼 제한은 [PRIVACY.md](PRIVACY.md)를 따른다.

## 로컬 검증

2026-10-13 엔진 167개, Anna Python 57개, UI 단위 52개, 브라우저 60개와 strict manifest 검사가 통과했다. 기존 세이브 읽기 무변경, 발견 보정, 입장 거절 시 미차감, 패배 재도전, 중복·동시 요청, 저장 오류 시 미지급, 자정 이후 기존 결과 재생, 계정별 격리, 임시 보너스 보존을 확인했다. 픽셀 PNG 크기·투명 여백·연결된 흰 배경 제거, 새 펫·단계·원본 교체 구분, AI 무호출, 최초 저장 및 실패 재시도, 360px·동작 줄이기도 검증했다. 실제 Anna 제공자와 파일 저장소가 아닌 격리된 브라우저 호스트 테스트다.

같은 날 Anna 테스트 앱 0.4.0 / working revision 34와 실행 도구 0.2.0 배포를 완료했다. 설치 앱의 정상 연결과 새 모듈 HTTP 200, 실제 실행 도구의 버전·로딩·실행 상태를 확인했다. 현재 계정은 새 캐릭터 생성 대기 상태여서 실제 픽셀 파일 저장과 탐험 플레이 확인은 남아 있다. [배포 기록](RELEASE_040.md)을 따른다.
