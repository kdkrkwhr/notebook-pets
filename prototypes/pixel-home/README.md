# 집과 마당 · 움직임 시제품

2026-10-16. 사용자 참조 화면의 탑다운 시점과 공간 비율을 확인하는 독립적인 시제품이다. **Anna에 배포된 앱은 여전히 1.4.1**이며 이 폴더는 앱 번들에 포함되지 않는다.

## 직접 보기

저장소 루트에서 다음 명령을 실행한다.

```powershell
python -B -m http.server 5194 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:5194/prototypes/pixel-home/`를 연다. 로컬 파일을 더블클릭하면 모듈/이미지 좌표 로딩이 제한될 수 있다. 개발 확인용 서버이며 배포 서버를 새로 도입하는 것이 아니다.

- **그대로 보기:** 예시 친구가 자동으로 마당을 돌고 집으로 들어갔다가 나온다.
- **잠깐 멈추기 / 다시 걷기:** 자세와 발밑을 확인한다.
- **마당부터 보기 / 집 안 보기:** 해당 장면의 자동 경로를 처음부터 시작한다.
- **− / +:** 1~5배로 확대·축소한다. 카메라는 친구를 따라간다.
- **발밑·가림 기준 보기:** 발밑 점, 물체의 충돌 영역과 깊이 기준, 예정 경로를 표시한다.
- 시스템의 동작 줄이기 설정에서는 처음에 멈춘다. 버튼으로 명시적으로 재생할 수 있다.

## 이번에 확인할 세 가지

1. **캐릭터:** 앞·왼쪽·오른쪽·뒤의 서로 다른 스프라이트. 방향마다 접지/교차 프레임이 달라지고 정지 시 중립 자세로 돌아온다. 전체 그림의 회전/상하 흔들림은 사용하지 않는다.
2. **공간:** 별도 집 외관·나무·벤치·책장·책상·둥지·화분·러그를 타일 지형 위에 렌더링한다. 완성된 방 이미지 한 장을 이동 배경으로 사용하지 않는다.
3. **움직임:** 이동 거리와 보행 프레임을 연결하고 출발/도착 속도를 완화한다. 발밑 충돌을 검사하고 같은 바닥 Y 순서로 오브젝트와 친구를 그린다. 나무 뒤에서는 실제로 가려진다.

마당은 40×30개의 16px 셀, 실내는 28×22셀의 시각 실험 공간이다. 게임 내 방 크기나 구매 가능 영역을 확정한 수치가 아니다. 미리보기의 경로는 시각 검증 전용이다. 실서비스의 배치·경로·보상·잔액·타이머는 Python 코어에서 권위 있게 검증해야 한다.

## 범위와 남은 작업

- 지금 친구는 새로 만든 **공용 예시 캐릭터**다. 사용자의 실제 친구·사진을 변환하거나 대체하지 않았다.
- 네 방향 보행과 정지까지 확인한다. 앉기·책 읽기·운반·개체별 특수 신체 동작에는 별도 프레임이 필요하다. 벤치/둥지에서는 현재 옆에 서서 쉰다.
- 가구 구매, AI 배치, 기존 저장 연결, 캐릭터 생성 파이프라인, Anna/웹 제품 통합은 포함하지 않는다. 런타임 AI 호출·게임 저장·외부 서비스 요청이 없다.
- 가구 배치 밀도, 맵 디테일, 개별 프레임의 실루엣/발 위치, 실제 친구의 정체성 유지와 생성 실패 복구는 후속 검수 대상이다. 이 시제품을 상용 게임 수준의 완성된 아트로 간주하지 않는다.
- 새 자산은 내장 `image_gen`으로 만들었다. 생성 원본 PNG를 그대로 보관하고 렌더링 시 atlas 좌표로 분리한다. [자산 생성 프롬프트와 해시](ART_PROMPTS.md).

## 검증

`anna/`의 잠금된 Playwright 의존성과 로컬 Edge(Windows) 또는 Playwright Chromium이 필요하다. 위 서버를 켠 상태에서 저장소 루트에서 실행한다.

```powershell
node prototypes/pixel-home/verify.mjs
```

검증 완료: 400초 상당의 경로에서 발밑 충돌 없음, 네 방향·보행 프레임 전환, 반복 실내외 이동, 정지 상태 보존, 나무 뒤 깊이 순서, 확대/축소·실내외 버튼, 375×812 모바일 가로 넘침 없음, 동작 줄이기, 브라우저 예외/외부 요청 0건. 스크린샷은 공개하지 않는 `.local/pixel-home-study/`에 기록된다. 이 검사는 미술 품질에 대한 사용자의 판단을 대신하지 않는다.
