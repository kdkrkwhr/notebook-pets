# Notebook Pets · 노트버디

**한국어** · [English](README.en.md)

[문서 목차](docs/README.md) · [현재 설치·배포 상태](anna/HANDOFF.md)

**내가 그린 작은 친구와 대화하고, 돌보고, 함께 모험하세요.**

노트버디는 한 마리의 AI 친구와 일상을 쌓아 가는 육성 게임입니다. 직접 그린 그림이나 사진으로 친구를 만들고, 밥을 주고 이야기를 나누며 성장시킬 수 있어요. 산책길에서는 이어지는 이야기와 픽셀 던전을 만나고, 돌아와서는 성장 앨범과 아이템 도감을 펼쳐 보세요.

## Windows·Mac 설치판 다운로드

**NoteBuddy Desktop 0.1.0a3 · 미리보기** — PC에 설치해 그림·사진으로 친구를 만들고, 대화·돌봄·산책·진화·마이홈을 즐겨 보세요.

**새 기능: Claude Code 연결** — Claude 구독만으로 대화·그림 분석과 캐릭터 제작을 이용할 수 있어요. Claude가 SVG로 그린 캐릭터를 PC에서 PNG로 저장하며, 그림은 벡터 일러스트풍입니다. Codex 계정이나 별도 이미지 API 키는 필요하지 않아요.

**밖으로 부르기** — AI 설정 옆 버튼을 누르면 내 픽셀 친구가 바탕화면을 돌아다녀요. 밖에 있는 동안 앱의 사진 자리는 흰색으로 비워지고, 안으로 부르면 다시 나타납니다. 이 기능에는 AI 사용량이 들지 않아요.

AI 기능은 **내 PC에 설치하고 로그인한 Codex CLI 또는 Claude Code**를 사용합니다. 설치 후 **AI 연결 설정 → 사용할 AI 선택 → 설정 저장 → 연결 확인**으로 시작하세요. 인터넷과 선택한 계정의 이용 한도가 필요하며, Anna 계정은 필요하지 않습니다. 구독료만 쓰려면 Claude 계정의 유료 추가 사용량(Usage credits / Extra usage)을 꺼 주세요. 게임·대화·이미지는 PC에 저장하며, AI 제공자를 바꿔도 유지됩니다. Anna·웹 세이브와는 별개입니다.

초기 미리보기에는 Windows 코드서명·Apple 공증이 없어 OS 경고가 표시될 수 있습니다. Windows에는 WebView2 Runtime이 필요합니다. 업데이트는 수동 설치 방식입니다.

## 그림 한 장에서 시작하는 우리 친구

마우스나 터치로 간단한 그림을 그려도 좋고, 이미 가지고 있는 그림·사진을 올려도 좋아요. 친구의 이름을 정하고 만나기를 누르면 AI가 몸의 형태와 색, 특징을 살펴보고 새 캐릭터를 그려 줍니다.

## 밥도 주고, 오늘 있었던 일도 들려주세요

먹이와 간식을 챙겨 주고, 놀아 주고, 훈련하고, 잠을 재워 주세요. 포만감과 친밀도를 살피며 하루 한 번 출석 선물과 일일 퀘스트 보상도 받을 수 있어요.

대화창에는 오늘 있었던 일이나 친구에게 하고 싶은 말을 적어 보세요. 친구의 성격과 최근 대화, 함께한 경험을 참고해 답하며, 돌봄 뒤에도 짧게 반응합니다.

**성격도 함께 쌓여요.** 이름과 외형에서 시작한 말투·습관에 돌봄, 훈련, 산책, 모험의 경험이 더해집니다. 호기심·친화성·활동성·신중함의 변화는 성격 화면에서 살펴볼 수 있고, 대화와 산책 이야기에 반영돼요. 채팅 문장만으로 성격 수치가 바로 바뀌는 방식은 아닙니다.

## 함께 사는 집과 마당

1.4.2에서는 나의 홈을 넓은 픽셀 게임 공간으로 만날 수 있어요. 마당을 걷고 집 안으로 들어가는 친구를 가까이 보거나 잠시 멈춰 구경할 수 있어요. 가구는 상점에서 사고, 배치는 친구에게 맡겨 주세요.

**마이홈 첫 접속에서 AI 픽셀 캐릭터 또는 무료 기본 이미지를 선택해요.** AI 생성은 이미지 요청 한 번을 사용하며, 기본 이미지는 현재 초상화를 무료로 픽셀 변환합니다. 저장된 모습은 홈과 던전에서 함께 쓰고 이동·재입장 때 다시 생성하지 않아요. 실내 12종과 마당 36종, 총 48종을 공간·취향별로 구입해 친구에게 배치를 맡길 수 있어요. [자세한 사용 안내](anna/README.md)

## 함께 자란 모습을 앨범에

**레벨이 올랐다고 바로 진화하지 않아요.** 레벨과 활동 조건을 채운 뒤, 친구 정보의 경험치 바 아래 **진화** 버튼을 눌러 원하는 때에 성장기·성숙기·완전체로 한 단계씩 진화하세요.

**세 가지 방향 중 어떤 친구로 자랄지 직접 골라요.** AI가 돌봄·훈련·산책, 최근 대화와 이전 진화의 기억을 참고해 외형과 속성 방향을 제안합니다. 지금 속성을 유지하거나, 바람처럼 신속하고 냉철하게 또는 밝고 건강한 요정의 기운으로 자랄 수 있어요. 선택지의 설명과 외형은 친구마다 달라집니다.

## 산책길에서 이야기를 고르세요

산책은 경험치를 찾거나 다른 몬스터를 만나는 작은 외출이에요. 이야기를 만나면 두 선택지 중 하나를 고르고, 그 선택의 결과를 확인할 수 있습니다.

현재는 **6종류의 3장 연속 이야기**가 있어요. 앞선 선택과 돌봄·모험의 경험이 다음 사건과 준비 조건, 결말에 영향을 줍니다. 도중에 닫아도 **산책 이어가기**로 돌아올 수 있어요.

산책 횟수는 현재 **5분마다 1개씩, 최대 5개**까지 회복됩니다.

산책하다 보면 확률로 던전을 발견합니다. 발견한 던전은 **24시간** 동안 열려 있고, 남은 시간이 화면에 표시돼요. 하나를 발견했다면 클리어하거나 문이 닫힐 때까지 다른 던전은 나오지 않습니다.

**1.2.0부터 던전 아이템을 모을 수 있어요.** 마지막 수호자를 클리어하면 그 지역의 미보유 일반 아이템을 하나 받고, 일반 3종 다음 클리어에는 희귀 아이템을 받아요. **내 보관함**에서 보유 현황을 확인하세요. 중복 지급과 과거 클리어 소급 지급은 없으며 지역별 4종을 모은 뒤에는 기존 코인만 받아요. 공용 4종·상점·착용은 아직 제공하지 않습니다. 보관함·도감 조회와 보상 지급에는 AI를 사용하지 않아요.

앞으로 착용 기능에서는 캐릭터의 몸 형태를 먼저 확인할 예정이에요. 손이 없는 친구도 장갑을 수집할 수 있지만, 장갑을 끼우려고 없던 손을 만들지는 않아요. 주변을 맴도는 별빛 같은 장식은 팔다리가 없어도 사용할 수 있도록 계획하고 있습니다.

## 어디서 사용할 수 있나요?

| 방식 | 현재 상태 |
| --- | --- |
| **Anna 앱** | 심사를 통과한 **1.4.13 공개 버전**을 사용할 수 있어요. [Anna 스토어에서 다운로드](https://anna.partners/store/@kdkrkwhr/notebuddy) · [앱 사용 안내](anna/README.md) |
| **오픈소스 엔진·Discord·AI 에이전트** | 직접 실행하거나 연결할 수 있어요. Anna 전용 화면·산책 이야기·도감과는 제공 범위가 달라요. [설치와 연결 안내](docs/DEVELOPMENT.md) |

Anna 화면은 **한국어와 영어**를 지원합니다. 상단에서 언어를 선택하면 새 답변도 그 언어로 받을 수 있어요. 친구와 최근 대화·성장 기록은 사용자별로 저장됩니다.

대화, 선택한 돌봄 반응·산책 이야기, 초기 성격, 그림·사진 분석과 초상화 생성, 선택한 마이홈 픽셀 캐릭터와 ‘꾸며 줘’에는 **Anna 계정의 AI 사용량**이 적용됩니다. 채팅 위에서 돌봄 AI를 끄면 행동·상태·보상은 처리하고 AI 반응과 산책 이야기는 생성하지 않아요. 직접 보내는 채팅은 AI를 사용합니다. 랜덤 친구의 그림은 기본 제공되지만 초기 성격은 AI를 사용해요. 구매·미리보기·이동·무료 픽셀 변환은 AI를 호출하지 않습니다.

## 앞으로 함께 만들 것들

지역 아이템 수집·보관함과 **집·마당 꾸미기 상점**은 사용할 수 있어요. 캐릭터 아이템 착용은 후속 기능이며, 원본을 유지하는 착용 그림 생성은 이미지 편집 API 지원과 품질 확인 후 연결해요.

**침몰한 왕궁·잊혀진 태엽도시는 지금 탐험할 수 있어요.** 이후 공중성·도서관·사막 테마를 계획하고 있습니다. 착용과 후속 지역은 아직 제공하지 않아요. [아이템 계획](anna/docs/ITEMS.md)
