# NoteBuddy Desktop 0.1.0a3

- AI 연결 설정에서 **Codex CLI / Claude Code**를 선택할 수 있습니다. 기존 Codex 설정과 모든 게임 데이터는 유지됩니다.
- Claude 구독에 로그인한 공식 Claude Code로 대화, 그림·사진 분석, 캐릭터 제작을 처리합니다. Codex 계정이나 별도 이미지 API 키가 필요하지 않습니다.
- Claude가 SVG로 그린 캐릭터를 PC에서 PNG로 저장합니다. 벡터 일러스트풍이며 Codex 이미지 모델과 스타일이 다릅니다. 외부 이미지 서비스나 임의의 생성 코드를 실행하지 않습니다.
- 제공자별 CLI 경로·모델을 저장하고, AI 요청 중 전환을 막습니다. 실패·취소 시 자동 재시도나 다른 AI로의 전환은 없습니다.
- 구독 한도와 Claude 계정의 유료 추가 사용량 설정을 안내합니다. 구독료만 쓰려면 계정에서 Usage credits / Extra usage를 꺼야 합니다. 앱은 추가 사용량을 구매하거나 결제 설정을 바꾸지 않습니다.
- Windows x64, macOS Apple Silicon·Intel용 패키지를 제공합니다. 기존 밖으로 부르기, 마이홈과 게임 규칙을 유지합니다.

새 버전을 설치한 뒤 **AI 연결 설정 → Claude Code → 설정 저장 → 연결 확인**으로 시작하세요.
공식 Claude Code 설치 및 구독 로그인(`claude auth login`)이 필요합니다.
자동 업데이트는 아직 없으며 앱을 종료하고 새 설치 파일을 실행하면 기존 세이브를 이어서 사용합니다.

# NoteBuddy Desktop 0.1.0a2

[GitHub 미리보기 릴리스 · 설치 파일 다운로드](https://github.com/kdkrkwhr/notebook-pets/releases/tag/desktop-v0.1.0a2)

- AI 연결 설정 옆에 **밖으로 부르기 / 안으로 부르기**를 추가했습니다.
- 친구를 별도의 투명한 바탕화면 창으로 불러 걷고 쉬게 합니다. 드래그로 옮기고 오른쪽 클릭·더블클릭으로 돌아오게 할 수 있습니다.
- 밖에 있는 동안 앱의 초상화 영역은 흰색으로 비워지고, 돌아오면 원래 사진이 복원됩니다. 저장된 사진을 수정하거나 삭제하지 않습니다.
- 현재 캐릭터와 외형에 맞는 마이홈 움직임 이미지를 재사용합니다. 없으면 현재 초상화를 무료로 픽셀 변환합니다. 이 기능은 AI 요청을 보내지 않습니다.
- 초기화·진화·초상화 변경 시 이전 바깥 캐릭터를 자동으로 닫습니다. 앱 종료 시에도 바깥 창을 정리합니다.
- Windows는 WinForms, macOS는 Cocoa의 작은 투명 창을 사용합니다. 기존 게임 규칙·세이브 형식은 유지합니다.

# NoteBuddy Desktop 0.1.0a1

첫 Windows·Mac 설치판 미리보기입니다. Anna UI 1.4.16과 게임 규칙 0.9.7을 바탕으로 합니다.

[GitHub 미리보기 릴리스 · 설치 파일 다운로드](https://github.com/kdkrkwhr/notebook-pets/releases/tag/desktop-v0.1.0a1)

- 네이티브 앱 창에서 기존 그림·사진 탄생, 대화, 돌봄, 진화, 산책·던전, 마이홈, 도감을 실행합니다.
- 세이브·대화·이미지는 이 PC의 SQLite 저장소에 보관합니다. Anna 계정은 사용하지 않습니다.
- 사용자가 설치하고 로그인한 Codex CLI로 대화·그림 분석·이미지 생성을 연결합니다.
- AI 연결 설정, CLI 확인, 모델 선택, 요청 취소, 저장 폴더 열기, 백업 내보내기를 추가했습니다.
- 영어 기본값, 한국어·일본어·중국어 간체·번체를 유지합니다.
- 새 요청마다 별도 임시 작업 폴더와 세션을 사용하며 명령 실행·브라우저·컴퓨터 제어 도구를 비활성화합니다.
- Windows x64 설치 프로그램과 macOS Apple Silicon·Intel용 DMG를 각각 제공합니다.

게임 규칙은 기존 Python 코어를 재사용합니다. AI 답변이 보상이나 상태를 직접 수정하지 않습니다.
첫 홈 방문의 무료 이미지 선택, 저장만 재시도, 구매·이동 시 AI 호출 금지 규칙도 유지됩니다.

초기 한계: 수동 업데이트, CLI 직접 설치·로그인 필요, Anna 세이브 이전과 기기 간 동기화 없음,
백업 복원 UI 없음, Windows 코드서명 및 Apple 공증 없음. Mac의 실제 계정으로 AI 연동하는 검증은 별도입니다.

검증 상세와 패키지 빌드 결과는 [HANDOFF.md](HANDOFF.md)에 기록합니다.
