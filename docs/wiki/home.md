# 마이홈과 픽셀 캐릭터

마이홈은 집 바깥과 마당, 문으로 들어가는 실내를 오가는 공간이에요. 배경, 가구, 친구를 각각 그려서 같은 픽셀 세계 안에서 움직이게 해요.

## 가구를 사고 친구에게 꾸미기를 맡겨요

사용자는 물건을 구매하고 **꾸며 줘**를 요청해요. 코어가 가능한 배치 후보를 만들고, AI는 제공된 후보 중 하나와 짧은 이유를 선택해요. 이후 코어가 재화, 소유권, 공간과 통로, 배치 revision을 다시 확인해요.

규칙은 [home.py](../../engine/home.py), 공간 정의는 [home_world.py](../../engine/home_world.py), 화면 연결은 [home.mjs](../../anna/bundle/home.mjs)에 있어요. 사용자가 좌표를 직접 끌어 놓는 편집기는 제공하지 않아요.

구매나 홈 열기만으로 자동 꾸미기를 요청하지 않아요. 물건을 옮기는 연출, 이전 배치 복원, 저장만 재시도하는 작업도 새 AI 선택을 요청하는 계기가 아니에요.

## 첫 방문에 움직이는 모습을 선택해요

새로운 초상화로 홈에 처음 들어가면 다음 두 방식을 선택할 수 있어요.

| 선택 | 처리 |
| --- | --- |
| 픽셀 캐릭터 생성 | AI 이미지 요청 한 번으로 방향별 동작이 있는 시트를 만들어요. |
| 기본 이미지 사용 | 현재 초상화를 로컬에서 픽셀로 변환해 저장해요. 별도의 방향별 포즈를 만들지는 않아요. |

[home-sprite.mjs](../../anna/bundle/home-sprite.mjs)의 `currentHomeAppearance()`와 `homeNeedsChoice()`는 저장된 모습과 원본의 관계를 확인해요. [pixel-pet.mjs](../../anna/bundle/pixel-pet.mjs)는 무료 픽셀 변환을 담당해요.

친구 생성이나 초상화 저장만으로 동작 이미지를 자동 생성하지 않아요. 저장된 선택은 재방문과 이동에서 재사용하고, 단계 숫자만 바뀌었다고 이미지 AI를 자동 호출하지 않아요. 새 초상화에는 별도의 첫 방문 선택이 생길 수 있어요.

## 홈과 던전에서 같은 친구를 사용해요

[home-scene.mjs](../../anna/bundle/home-scene.mjs)는 타일과 오브젝트, 친구의 위치와 가림 관계를 그려요. [home-walk.mjs](../../anna/bundle/home-walk.mjs)는 이동을 다루고, [dungeon-avatar.mjs](../../anna/bundle/dungeon-avatar.mjs)는 던전에 표시할 모습을 연결해요.

캐릭터와 원본 이미지가 달라졌다면 이전 동작 시트를 그대로 현재 모습으로 인정해서는 안 돼요. 이 때문에 모습의 캐릭터 ID와 원본 경로를 함께 검사해요.

## 실패하면 받은 결과를 보존해요

이미지 생성 실패 뒤에는 무료 기본 모습을 사용하며 유료 생성을 자동으로 반복하지 않아요. 이미지 결과는 받았지만 저장이 실패했다면 같은 창에서 받은 결과의 저장을 다시 시도해요. 창을 닫아 결과가 사라졌다면 저장만 재시도할 수 있는 것처럼 안내하지 않아요. 플랫폼별 사용 흐름은 [웹 안내](../../web/README.md)에서 확인할 수 있어요.
