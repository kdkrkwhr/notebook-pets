# 노트버디 프로젝트 위키

노트버디는 그림이나 사진에서 나만의 친구를 만들고, 대화와 돌봄으로 함께 성장하는 앱이에요. 산책에서 던전을 발견하고, 모은 코인으로 집과 마당도 꾸밀 수 있어요. 이 위키는 그 경험이 어떤 코드와 규칙으로 이어지는지 설명해요.

## 하나의 규칙을 여러 환경에서 사용해요

화면에서 행동을 고르면 공통 Python 엔진이 가능 여부와 결과를 계산해요. 플랫폼 어댑터가 그 결과를 저장한 뒤 화면에 보여줘요. 대화나 그림을 만드는 AI는 이 흐름에 필요한 표현을 보태요. 재화와 보상, 진화 조건을 최종 결정하는 곳은 게임 규칙이에요.

웹은 브라우저의 Pyodide에서 Python을 실행하고, Anna는 도구 어댑터를 통해 같은 코어를 사용해요. 자세한 경계는 [game_api.py](../../engine/game_api.py), [웹 Worker](../../web/worker.js), [Anna Worker](../../anna/executas/notebuddy/game_worker.py)에서 확인할 수 있어요.

## 기능 해설과 자동 문서를 함께 읽어요

한국어 기능 해설은 LLM이 실제 소스와 문서를 대조해 작성한 설명이에요. 코드의 의도를 이해하고 관련 파일을 찾을 때 사용해요.

[Graphify 자동 문서](graphify/index.md)는 코드 관계 그래프에서 추출한 묶음, 주요 함수와 연결을 보여줘요. 이 부분은 배포할 때 자동으로 다시 생성하며 LLM API를 호출하지 않아요. 연결 수가 많다는 사실만으로 설계상 중요도가 확정되지는 않고, 동적 호출이나 JavaScript와 Python 사이의 연결은 분석에서 빠질 수 있어요.

현재 위키는 `release-web`의 소스를 기준으로 해요. Anna에 설치된 버전이나 심사본의 기능을 확인하는 페이지는 아니에요. 웹에서 가능한 기능과 Anna에서 가능한 기능은 [플랫폼 비교](platforms.md)에서 구분해서 볼 수 있어요.
