# 캐릭터 탄생과 진화

Anna에서는 직접 그린 그림이나 업로드한 사진을 친구의 출발점으로 사용할 수 있어요. 눈에 보이는 특징을 분석한 뒤 그 묘사를 바탕으로 새 캐릭터 그림을 만드는 흐름이에요.

## 그림과 사진을 읽는 과정

[birth-art.mjs](../../anna/bundle/birth-art.mjs)는 PNG·JPEG·WebP 입력을 확인하고 크기를 정리해요. `checkArtwork()`는 이미지를 LLM 입력으로 보내 형태, 색, 무늬와 종족·속성 후보를 받아요. 응답은 허용된 값과 길이를 검사한 뒤 사용해요.

관찰 문구는 보이는 신체 구조를 유지하도록 요청해요. 다리가 없는 모습과 화면 밖으로 가려진 모습을 구분하고, 사진 속 사람의 신원이나 실제 성격을 추정하지 않도록 구성돼 있어요. 이것은 요청과 검증의 설계이며 생성 결과가 항상 원본과 일치한다는 보장은 아니에요.

## 관찰한 특징으로 새 모습을 그려요

`birthPrompt()`는 관찰한 특징을 이미지 생성 문구에 넣어요. 종족이나 속성보다 원본의 실루엣과 신체 구조를 우선하도록 요청해요. 이 흐름은 이미지를 그대로 편집하는 image-to-image와 구분돼요. 그림 분석과 생성 절차는 [birth-flow.mjs](../../anna/bundle/birth-flow.mjs)에서 연결돼요.

현재 웹의 **새 그림 저장**은 완성된 이미지 파일을 가져오는 기능이에요. Anna의 최초 그림 분석·탄생 절차 전체가 웹에도 제공되는 것은 아니에요. [웹 안내](../../web/README.md)에서 플랫폼별 사용법을 확인할 수 있어요.

## 조건을 채우면 직접 진화 방향을 골라요

레벨만 올랐다고 바로 진화하지 않아요. [evolution.py](../../engine/evolution.py)의 `progress()`가 레벨과 누적 활동을 확인하고, 진행 중인 선택을 끝내야 하는지도 검사해요. 실제 목표값은 [game_data.json](../../data/game_data.json)의 `evolution_requirements`에 있어요.

| 다음 단계 | 조건 |
| --- | --- |
| 성장기 | 레벨 10, 돌봄 10회, 산책 3회 |
| 성숙기 | 레벨 30, 돌봄 30회, 훈련 10회, 산책 15회 |
| 완전체 | 레벨 50, 돌봄 60회, 훈련 25회, 산책 30회, 이야기 완결 3회 |

돌봄 횟수는 밥·간식·놀기·잠자기를 합쳐 계산해요. 준비된 세 방향 중 첫 번째는 현재 속성을 유지하고, 나머지는 허용된 속성 변화 방향을 제안해요.

## 진화와 그림 저장을 구분해요

[evolution.mjs](../../anna/bundle/evolution.mjs)는 현재 외형, 활동 기록, 성격, 최근 대화와 이전 진화의 기억을 바탕으로 제안을 요청해요. 제안 요청은 1회, 선택한 새 초상화 생성은 별도 이미지 요청 1회로 구성돼요. AI 제안이 실패하면 기본 방향을 사용하고, 새 그림을 만들지 않고 진화할 수도 있어요.

진화는 저장됐는데 그림 생성이 실패하면 이전 그림을 유지해요. 이미 받은 이미지의 저장만 실패한 경우에는 같은 결과를 다시 저장해요. [픽셀 캐릭터](home.md)는 새 초상화를 저장하는 순간 자동으로 유료 생성하지 않고, 해당 모습으로 처음 홈에 들어갈 때 선택해요.
