# 산책과 던전

산책은 친구의 경험을 쌓고 새로운 지역을 발견하는 활동이에요. 발견한 던전은 제한된 시간 동안 열리며, 탐험의 결과와 보상은 Python 규칙이 계산해요.

## 한 번에 하나의 던전을 발견해요

[dungeons.py](../../engine/dungeons.py)의 `discover()`는 발견 중인 지역과 진행 중인 탐험이 없는지 먼저 확인해요. 발견 판정의 확률은 25%이고, 새 던전의 유지 시간은 발견 시점부터 24시간이에요. 매일 자정에 새 발견의 시간을 초기화하는 방식은 아니에요.

이미 발견한 던전이 있으면 클리어하거나 만료되기 전까지 추가 발견하지 않아요. 실제 산책 행동과 발견 판정을 연결하는 곳은 [engine.py](../../engine/engine.py)예요. 산책의 선택과 이야기 기록은 [journeys.py](../../engine/journeys.py)와 [journey-stories.mjs](../../anna/bundle/journey-stories.mjs)에서 다뤄요.

## 현재 들어 있는 다섯 지역

| 지역 | 적응 보너스를 받는 종족 |
| --- | --- |
| 지옥문 | 용, 괴수, 유령 |
| 얼음왕국 | 포유류, 조류, 기계 |
| 몽환의 숲 | 식물, 요정, 파충류 |
| 침몰한 왕궁 | 파충류, 식물 |
| 잊혀진 태엽도시 | 기계, 괴수 |

다른 종족도 입장할 수 있어요. 지역 목록과 보너스는 `CATALOG`, `BONUS_PERCENT`에 정의돼 있어요. 입장 화면은 보스 속성과 내 공격 상성, 적응 보너스를 표시해요.

## 방을 지나며 탐험해요

`room_plan()`은 해당 발견의 지역과 날짜를 바탕으로 3~6개의 방을 구성해요. 전투방과 마지막 수호자가 있고, 방 수에 따라 휴식 공간이 포함돼요. 같은 발견을 다시 시도한다고 방 수를 무작위로 다시 고르지는 않아요.

[dungeon.mjs](../../anna/bundle/dungeon.mjs)는 탐험과 선택 화면을 연결하고, [dungeon-scene.mjs](../../anna/bundle/dungeon-scene.mjs)는 이동과 전투를 보여줘요. 화면의 일시정지나 빠르게 보기는 표현을 제어해요. 보상이나 이미 저장한 결과를 애니메이션이 새로 결정하지 않아요.

## 도감과 수집 기록이 이어져요

지역 아이템은 [collectibles.py](../../engine/collectibles.py)와 [item-catalog.mjs](../../anna/bundle/item-catalog.mjs)에서 규칙과 화면을 나눠 관리해요. 도감과 보관함의 수집 기능, 캐릭터의 몸에 실제로 착용하는 기능은 구분해야 해요. 현재 착용 그림 생성은 후속 기능으로 안내돼 있어요. [프로젝트 소개](../../README.md)와 [아이템 계획](../../anna/docs/ITEMS.md)을 함께 참고해 주세요.
