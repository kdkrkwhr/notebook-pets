# 노트버디 Android · 0.2.4 parity preview

Anna 공개 1.4.13의 기록된 패키징 소스 `246781d`를 직접 사용하고, Android 저장소와 무료 온디바이스 AI 연결부를 바꾸는 **PC 검증용 준비본**입니다. 새 이미지 생성의 속도·메모리·품질을 검증한 최종본이 아닙니다.

## 화면과 흐름

- Anna의 타이틀 → 만나는 방법·이름 → 만나기 흐름, 분석 프롬프트·종/속성·성격·진화·집 로직을 원본에서 직접 가져옵니다.
- 그림으로 만나기는 원본의 분석 → 친구 생성 → 특징 설명 기반 text2img → 자동 저장을 사용합니다. 별도 생성 버튼, 결과 미리보기 승인, 확정 저장 단계는 추가하지 않습니다. 분석이 불확실할 때의 확인과 실패 복구는 원래 Anna 흐름입니다.
- 모바일에서만 배치, 44px 터치 높이, 글자 크기, 키보드 스크롤을 조정합니다. 새 탭이나 온보딩은 추가하지 않습니다.
- 원본 파일은 해시로 고정하고, 모바일 스타일·저장·실행 연결부는 `anna-adapter`에 분리합니다. 자세한 변경 계약은 [ANNA_PARITY.md](ANNA_PARITY.md)를 참조하세요.

## 생성 지원 한계

Anna의 `1024x1024 / n=1 / low / 1K / PNG` 요청과 전체 프롬프트를 유지합니다. 원본 사진은 Gemma 분석에만 전달하며 SD 생성에는 텍스트만 전달합니다. img2img나 임의 저해상도로 대체하지 않습니다.

**현재 1024px CPU text2img는 명시적으로 실행 차단됩니다.** 지원 확인 실패는 기존 Anna의 실패·재시도 화면으로 전달됩니다. JNI 구현과 빌드는 준비했지만, 실제 실행은 별도의 실현 가능성 결정과 기기 검증이 필요합니다. 이 APK를 생성 기능 완성본으로 설치하지 마세요. 같은 제약이 진화 초상·집 픽셀 시트 생성에도 적용됩니다.

기존 별도 probe의 256px img2img는 174.9초·최대 RSS 5.45GiB였으며 품질 미통과였습니다. 1024px의 시간/메모리는 측정하지 않았습니다. 새 무료 모델·GPU 가속도 검증하지 않았습니다. 대화/그림 분석은 기존 Gemma를 사용하고, 원본의 요청 길이가 모델 문맥 한계를 넘으면 실패할 수 있습니다. 품질 개선을 보장하지 않습니다.

## 저장 보존과 모델

- `.lab.ondevice`에 같은 서명으로 업데이트할 준비를 하되, 이번 작업에서는 설치하지 않습니다. 원래 `.lab`·QA 앱을 지우지 마세요.
- 기존 IndexedDB의 `player`, `visuals`, `birth-draft`를 삭제하지 않고 새 Anna 저장 키로 원자적으로 복사합니다. 이전 형식 행은 보관합니다. 이전 미확정 미리보기는 자동 확정하거나 버리지 않습니다. 사용자에게 보여줄 별도 초안 복구 방식은 아직 결정하지 않았습니다.
- 이전 버전으로의 다운그레이드/새 저장의 역변환은 지원하지 않습니다. 이전 데이터가 남았다는 것이 이후 새 저장까지 옛 앱과 동기화된다는 뜻은 아닙니다.
- Gemma 파일이 있으면 첫 AI 요청에서 네트워크 없는 `verifyModel`로 검사합니다. 파일이 없거나 검증에 실패하면 오류를 표시하며 다운로드하지 않습니다.
- 원본·생성 결과는 별개 파일로 저장합니다. 실패한 저장은 같은 결과로 재시도하고 생성 요청을 자동 반복하지 않습니다. 앱 삭제·데이터 초기화는 보존 기능이 아닙니다.

## PC 검증

`python android/build_bundle.py`는 Git에 있는 고정 Anna 소스와 이미 설치된 Pyodide를 패키징합니다. 새 모델을 받지 않습니다. 얕은 clone이라면 기준 커밋이 필요하며 CI는 전체 이력을 체크아웃합니다.

```
node tests/pyodide/android-anna-parity.mjs
node tests/pyodide/android-anna-render.mjs
```

첫 검사는 실제 Pyodide 게임 서비스/규칙·IndexedDB와 합성 AI 응답으로 자동저장/재실행/중복요청/충돌/이전/미지원/실패/취소/저장만 재시도를 검사합니다. 둘째는 같은 합성 입력/상태에서 원본·모바일 화면을 렌더 비교합니다. 어느 것도 실제 모델 품질이나 Android 실기기 검증을 대신하지 않습니다.

기존 6066cad의 img2img UI 테스트와 구현은 이력/소스에 보존합니다. 그 테스트는 현재 UI 검증으로 실행하지 않습니다. Android instrumentation APK 빌드와 instrumentation 실제 실행도 구분합니다. 이번 단계에서는 폰 조작·새 설치·모델 추론이 없습니다.
