    03 / FIND A STARTING POINT

    이 기능은 어디에 있을까요?

    분석한 커밋의 GitHub 소스로 연결됩니다.

      READ THIS MAP

      지도가 보여주는 범위

      공개 애플리케이션 코드만 분석했어요. engine/, web/, anna/bundle/, anna/executas/notebuddy/의 Git에 기록된 Python·JavaScript 코드가 대상이에요. 테스트·과거 문서·빌드 산출물·사용자 저장 데이터는 대상에 포함하지 않아요.

      Graphify의 로컬 AST 분석으로 만들었으며 문서 의미 분석이나 AI API는 사용하지 않았어요. EXTRACTED는 소스에서 직접 추출한 연결, INFERRED는 분석기가 추론한 연결이에요. 동적 호출, Web Worker·Python 사이의 메시지, 플랫폼 API 연결 등은 빠질 수 있어요. 연결이 없다고 실제 의존성이 없는 것은 아니에요.

      Pages 배포 때마다 해당 커밋을 다시 분석해요. 여기의 Anna 코드는 release-web에 포함된 스냅샷으로, 현재 설치된 Anna 앱 또는 심사 버전과 같다는 뜻은 아니에요.
