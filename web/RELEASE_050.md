# Web 0.5.0 · 웹 전용 로컬 AI

대화·가구 배치에 Gemini/Ollama, 방향별 동작 이미지에 Gemini/ComfyUI를 각각 선택할 수 있다. 모두 로컬로 선택하면 Gemini 키 없이 같은 PC의 서버를 직접 호출한다. 서버·모델 목록 확인은 명시적으로 요청할 때만 하며 AI 추론을 실행하지 않는다. 로컬 요청 실패 시 Gemini로 전환하지 않고, Ollama의 클라우드 모델은 추론 전 거부한다.

ComfyUI는 사용자가 준비한 API 워크플로와 로컬 모델을 사용한다. 앱이 현재 참고 그림을 업로드하고 프롬프트·LoadImage 입력을 바꿔 한 번 제출한 다음 지정한 출력 시트 한 장을 가져온다. 선택한 출력에 프롬프트와 참고 이미지가 연결됐는지 검사하며, 기존 공통 시트 검사·저장·그림별 중복 생성 방지를 그대로 사용한다. 최대 4분 대기 후 자동 재제출하지 않는다. 큐 작업은 서버에서 계속될 수 있다.

AI 선택·주소·모델명·노드 번호만 이 브라우저에 기억한다. Gemini 키와 워크플로 파일은 탭 메모리에서만 사용하며 초기화/백업 교체/새로고침 시 비운다. 게임 백업에 넣지 않는다. 설정 변경만으로 이미지 AI를 호출하지 않는다. 가구 구매·홈/던전 입장·이동·되돌리기·저장 재시도는 AI를 호출하지 않으며 Python 규칙은 변경하지 않았다.

[설정 안내](LOCAL_AI.md). **Anna의 소스·버전·설치 UI·도구·심사 후보는 변경하거나 재배포하지 않는다.** 이 변경은 `release-web`에만 적용한다.

## 검증

- 제공자 단위 검사: 로컬 주소 제한, Ollama JSON/일반 대화 요청, 키 미전달, 클라우드 모델 차단, 워크플로 참고 이미지 연결, 한 번 제출, 실패/취소 시 재시도·클라우드 대체 없음.
- 실제 Pyodide/IndexedDB/화면과 모의 Ollama·ComfyUI: 키 없는 대화·배치·시트 저장, 구매/이동 무호출, 잘못된 배치 거부, 이미지 실패 후 동일 그림 중복 요청 방지, 워크플로 비영속화, 1120/360px.
- 기존 Gemini 기본/저장/백업/초기화, 홈/던전/저장 재시도/외형 변경/늦은 응답 차단, 7개 테마 검사 통과.
- 이 PC의 실제 Ollama 0.40.5 + 기존 qwen3:8b로 브라우저 대화와 게임 코어가 검증한 가구 배치 성공. Google 요청 0회.

ComfyUI 실제 모델 생성과 유료 Gemini 생성은 실행하지 않았다. ComfyUI 통합 검사는 모의 서버가 공개 프로토타입 시트를 반환한다. 임의 커스텀 노드 내부의 네트워크 동작, 출력의 캐릭터 유사도·방향 정확성은 검사만으로 보장하지 않는다. 신뢰할 수 있는 로컬 워크플로와 실제 출력 확인이 필요하다.

## 배포

기능 소스 `0b1fb80`, [Pages 빌드·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38892468339) 및 [공통 Linux/Windows/Pyodide 검사](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38892468355) 성공. 제공자 검사는 기존 `web.mjs` 검사 진입점에서 함께 실행한다.

실제 [공개 페이지](https://kdkrkwhr.github.io/notebook-pets/)의 격리 브라우저에서 qwen3:8b 로컬 실응답으로 대화·후보 배치 성공, 구매/이동 중 AI 미호출, Google 요청 0회, 페이지 오류 0을 확인했다. 브라우저의 로컬 네트워크 권한을 허용하고 정확한 사이트 출처를 CORS로 허용한 테스트 서버를 사용했다. 실제 사용자 공책에는 쓰지 않았다.

이 PC(Apple M5, 메모리 16GB)에 `qwen3.5:4b-q4_K_M` 약 3.3GB를 설치했다. 기본 `qwen3.5:4b`가 선택한 MLX 실행은 JSON 모드에서 501을 반환해 이 서비스의 가구 배치용으로 채택하지 않았다. 이번 작업에서 내려받은 MLX 태그는 정리하고 기존 qwen3:8b는 유지했다. 신규 GGUF 모델도 실제 공개 페이지에서 한국어 대화와 코어가 검증한 가구 배치를 통과했다. Google 요청 0회·페이지 오류 0이며, ComfyUI 응답만 모의 시트를 사용했다. 기본 11434 서버의 설정을 바꾸지 않고 웹 출처를 허용한 11435 로컬 서버를 사용했다. 사용자 환경에는 11435 서버와 설치 모델을 남겼으며 기존 서버/모델은 유지했다.

## 동작 준비 실패 진단 후속 · 2026-10-16 (0.5.0 유지)

Anna의 공통 동작 준비 모듈을 Git merge로 통합했다. 정적 픽셀 미리보기와 방향 동작 상태를 구분하고 실패 단계(참고 이미지/요청/응답/다운로드/검증/저장)를 안전한 코드로 기록한다. 웹의 실패 안내도 이 분류를 사용한다. 기존 Ollama/ComfyUI 선택·키 비영속화·그림별 한 번 요청·저장만 재시도·동일 그림/입장/이동 시 AI 미호출은 유지한다.

소스 `73c3cbc`, [Pages 빌드·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38894499755) 및 [공통 Linux/Windows/Pyodide CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38894499628) 성공. 실제 공개 URL의 HTML·home-sprite/i18n/웹 모듈 원본 일치, 1120/360px·기존 로컬 모델 목록·저장 불변·AI 요청 0·페이지 오류 0을 확인했다. 기본/제공자/홈/던전/테마 검사가 통과했다.

이번 후속은 dora의 Anna 오류 화면에 대한 별도 수정이다. Anna는 **1.4.5 소스 / working revision 62 / 소유자 테스트 초안**으로 반영했고 심사 후보와 게임 도구는 유지한다. 실제 Anna의 생성 실패 원인은 스크린샷만으로 확정하지 못했으며, 생성 자체가 해결됐다는 검증은 아니다. [Anna 인계](../anna/HANDOFF.md).

## 분리된 동작 부속 부위 판독 · 2026-10-17 (0.5.0 유지)

정상 4×4 시트의 작은 꼬리 끝·장식이 떨어져 있으면 추가 프레임으로 세던 오류를 공통 판독기에서 수정했다. 불균등한 행/열의 실제 간격 안에서 가까운 작은 부위만 모호함 없이 묶는다. 큰 별도 캐릭터·셀 경계·잘림·누락·겹침은 계속 거부한다. AI 재생성이나 원본 PNG 수정은 없다. 이전 실패 네발 친구를 포함한 동일 PNG 4종이 모두 16프레임으로 읽힌다.

배포 소스 `b81fa41f2780d1f31c0b5782d143ec2f6dbb62f2`, [Pages 검사·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38928214360)와 [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38928214277) 성공. 분리 부위가 있는 입력으로 웹 생성/저장만 재시도/홈·던전 재사용 통합 검사를 통과했다. 실제 공개 URL에서 로드된 모듈의 빌드 일치·기존 실패 PNG의 16프레임 판독·1120/360px·저장 불변·외부 요청 및 페이지 오류 0을 확인했다. 사용자 저장소는 건드리지 않았다.

Anna 소유자 테스트 초안은 **revision 63**, 심사 후보 **1.4.5 / ID 1417**은 교체하지 않았다. dora의 과거 실패 원인은 해당 원본 응답이나 로그 없이 확정하지 못하며, 버려진 생성 결과를 복구한 작업도 아니다. [최종 인계](../anna/HANDOFF.md).
