# Web 0.7.0 — 직접 선택하는 진화

- Anna 1.4.11의 공통 Python 진화 규칙을 Git으로 통합했습니다. 레벨과 누적 활동 조건을 만족한 뒤 사용자가 세 방향 중 하나를 고릅니다. 기존 성장 단계·친구 ID·아이템·코인은 보존합니다.
- 현재 그림을 분석하는 텍스트/비전 요청 한 번으로 외형 특징과 세 방향을 준비합니다. 최근 직접 보낸 대화, 돌봄·모험 기록과 이전 진화 요약을 참고합니다. AI는 외형 설명과 허용된 속성 방향만 선택하고 보상·능력치를 바꾸지 못합니다.
- 선택한 새 모습만 이미지 한 번으로 생성합니다. 진화 이미지 요청에는 참고 그림이나 이미지 편집 API를 사용하지 않습니다. 그림 생성 없이 진화할 수도 있습니다. 저장 재시도와 재접속은 유료 요청을 반복하지 않습니다.
- Gemini와 비전 지원 Ollama에서 특징 분석을 지원합니다. Gemini 또는 ComfyUI의 텍스트 기반 워크플로로 진화 초상화를 만듭니다. ComfyUI는 LoadImage 없는 워크플로가 필요하며, 마이홈 동작 시트는 기존 참고 이미지 방식입니다.
- 직접 나눈 대화는 최대 64개 메시지·40KB로 IndexedDB에 저장하며 백업/복원합니다. 진화에는 최근 사용자 메시지 최대 24개와 이전 진화 요약 600자까지 사용합니다. API 키·워크플로는 백업에 포함하지 않습니다.

검증: 실제 공통 엔진과 브라우저에서 수동 진화·특징 분석·텍스트 전용 이미지·재진입·로컬 모델·백업을 모의 AI로 확인합니다. 배포 결과는 [HANDOFF](../anna/HANDOFF.md)에 기록합니다. 실제 유료 이미지의 유사도와 생성 품질은 이번 검증 대상에 포함하지 않았습니다.
