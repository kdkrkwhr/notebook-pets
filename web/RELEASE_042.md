# Web 0.4.2 · 방향별 동작 생성 명세 보정

Anna 1.4.5의 공통 `home-sprite.mjs`를 Git merge로 통합했다. 좌우 화면 기준과 보행·정지·눈 감기의 방향 일관성, 다중 머리·장식 보존, 작은 표시 크기의 가독성을 구체화한다. 기존 저장·개인 그림을 자동 교체하거나 AI를 재호출하지 않는다. 개인 검수용 시트는 공개 웹에 포함하지 않는다.

실제 생성 이미지의 방향·외형은 프롬프트만으로 보장할 수 없다. 의미 검수는 여전히 필요하며 이번 보정도 Anna 제공자의 실제 참조 이미지 생성 성공을 증명하지 않는다.

배포 완료: 소스 `339181ef8ce271b268f7881825ca004e9ec9284d`, [Pages 검사·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38849826706) 및 [공통 CI](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38849826764) 성공. 로컬 웹 홈/던전/그림/저장 통합 검사도 통과했다.

[공개 URL](https://kdkrkwhr.github.io/notebook-pets/)을 별도 Edge 컨텍스트로 열어 `data-web-version=0.4.2`, 실제 로드된 `home-sprite.mjs`와 로컬 빌드 일치(줄바꿈 정규화), 1120/360px, 저장 스냅샷 동일, AI 요청 0회, 페이지 오류 0을 확인했다. 사용자의 기존 웹 저장소는 건드리지 않았다.

Anna는 **1.4.5 / ID 1417 / working revision 59**, 도구 **0.9.1 / Executa version 760**으로 테스트 설치를 확인했고, 요청에 따라 **심사 후보 1.4.5 / pending_review**로 교체했다. [Anna 배포 기록](../anna/releases/RELEASE_145.md).

## 전투·던전 안내 보완 · 2026-10-16 (0.4.2 유지)

게임 규칙 변경 없이 일반 전투 승패 집계 범위, 다섯 지역의 무작위 발견·당일 클리어 제외, 발견 후 24시간 만료와 자동 교체 없음, 새 탐험/재도전 최대 HP 및 스테이지 간 체력 유지·쉼터 회복을 안내한다. 미발견 상태에서도 발견 방법을 볼 수 있고, 미발견 입장 카드는 표시하지 않는다. Anna 공통 UI는 Git 병합으로 통합했다.

배포 소스 `e7d015d`, Pages run **38886276977** 성공. 실제 공개 URL에서 HTML·공통 모듈이 빌드와 일치하고, 1120/360px·입장 안내·안내 확인 중 저장 스냅샷 동일·AI 0회·페이지 오류 0을 확인했다. 로컬 기본/저장/백업·홈/던전·테마와 공통 Windows/Linux/Pyodide CI 통과. 개인 저장소 대신 격리 브라우저 컨텍스트를 사용했다. 웹 버전은 0.4.2로 유지한다.

Anna 안내 소스 `4f9257e`는 사용자 로그인 승인 후 working revision 60 / 소유자 초안 `0.0.0-draft`에 설치했다. 공식 WM/호스트 브리지로 실제 설치 번들의 한영·360px 안내와 클라우드 도구 0.9.1 실행을 확인했다. 모의 게임/AI 응답 없이 검증했고 앱 저장 4종 값/ETag 및 게임 inspect 응답이 동일하다. 일반 대시보드의 쿠키 로그인/사용자 브라우저 재접속은 별도 확인 범위다. 버전·심사 후보 1.4.5·스토어 소개·게임 저장은 변경하지 않았다. ## 가구 구매 확인창 수정 · 2026-10-16 (0.4.2 유지)

Anna와 공유하는 홈 구매 확인창을 앱 내부 dialog로 바꿨다. 기존 네이티브 confirm은 Anna의 allow-modals 없는 sandbox에서 false로 처리돼 구매 요청이 나가지 않았다. 한영 가구명·가격·취소·구매 확인·보관함과 ‘꾸며 줘’ 안내를 제공하며 구매만으로 자동 배치하거나 AI를 호출하지 않는다. Python 규칙·가격·권한은 그대로다.

배포 소스 `c8c5457`, [Pages 빌드·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38889927900) 성공. 실제 공개 URL의 격리 공책에서 구매 전 확인/취소와 Esc의 저장 보존, 구매 후 코인 100→90·책상 보유·기존 배치 유지·중복 구매 버튼 비활성·360px를 확인했다. HTML/home.mjs/home.css 원본 바이트 일치·AI 0회·페이지 오류 0이다. 로컬 기본/저장/백업·홈/던전·테마와 공통 Windows/Linux/Pyodide CI 통과. Anna 초안 working revision 61도 설치했고 실제 설치 확인창의 한영·모바일·취소/Esc 및 사용자 저장 보존을 검증했다. 버전·심사 후보는 유지한다. [상세 인계](../anna/HANDOFF.md).
