# Web 0.8.0 — 집에서 보내는 시간과 추억 노트

Anna의 검증된 공용 코어·UI를 Git으로 통합하고, 기존 Web의 IndexedDB·직접 AI 연결·그림 참조 어댑터를 유지합니다.

- 친구가 배치된 둥지·책장·화분 곁을 방문하며 활동을 짧게 표시합니다. 구경·이동·일시정지는 AI와 게임 저장을 요청하지 않습니다.
- 실제 첫 만남·진화와 각 지역에서 처음 기록한 수호자 승리를 보존합니다. 신뢰할 만한 과거 기록만 복원하며 날짜나 최초 승리를 추정하지 않습니다.
- 완료된 대화 원문을 최대 20개, 메시지당 3,000자, 문서당 UTF-8 40,000바이트까지 선택 저장할 수 있습니다. 삭제는 원래 대화에 영향을 주지 않습니다.
- 저장 문구는 별도의 로컬 기록으로 보관하고 기존 백업 형식의 선택 필드에 포함합니다. 기존 백업도 가져올 수 있습니다. 초기화와 같은 친구의 백업 재가져오기는 기존 epoch를 올려 늦은 기록 저장을 막습니다.
- 한국어 Web 화면에 공유 다섯 언어 모듈을 포함합니다. Web의 언어 선택 범위를 새로 늘리지는 않습니다. Web에서 아직 제공하지 않는 아이템 착용은 비활성으로 유지합니다.
- 추가 서버·클라우드 권한·유료 AI 요청이 없습니다. Gemini/Ollama/ComfyUI의 기존 직접 호출과 무료 기본 모습 선택을 유지합니다.

실제 IndexedDB 브라우저 검사에서 동시 저장·중복 방지·백업·오래된 백업·초기화/교체 뒤 지연 쓰기 차단과 320/390/1280px 추억 노트를 확인했습니다. 모의 채팅 1회 외에 노트 조작의 AI 호출은 0회입니다. 전체 Web 회귀와 배포 결과는 완료 후 기록합니다.

현재 상태: **소스 준비, 아직 push·공개 배포하지 않았습니다.**
