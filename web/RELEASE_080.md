# Web 0.8.0 — 집에서 보내는 시간과 추억 노트

Anna의 검증된 공용 코어·UI를 Git으로 통합하고, 기존 Web의 IndexedDB·직접 AI 연결·그림 참조 어댑터를 유지합니다.

- 친구가 배치된 둥지·책장·화분 곁을 방문하며 활동을 짧게 표시합니다. 구경·이동·일시정지는 AI와 게임 저장을 요청하지 않습니다.
- 실제 첫 만남·진화와 각 지역에서 처음 기록한 수호자 승리를 보존합니다. 신뢰할 만한 과거 기록만 복원하며 날짜나 최초 승리를 추정하지 않습니다.
- 완료된 대화 원문을 최대 20개, 메시지당 3,000자, 문서당 UTF-8 40,000바이트까지 선택 저장할 수 있습니다. 삭제는 원래 대화에 영향을 주지 않습니다.
- 저장 문구는 별도의 로컬 기록으로 보관하고 기존 백업 형식의 선택 필드에 포함합니다. 기존 백업도 가져올 수 있습니다. 초기화와 같은 친구의 백업 재가져오기는 기존 epoch를 올려 늦은 기록 저장을 막습니다.
- 한국어 Web 화면에 공유 다섯 언어 모듈을 포함합니다. Web의 언어 선택 범위를 새로 늘리지는 않습니다. Web에서 아직 제공하지 않는 아이템 착용은 비활성으로 유지합니다.
- 추가 서버·클라우드 권한·유료 AI 요청이 없습니다. Gemini/Ollama/ComfyUI의 기존 직접 호출과 무료 기본 모습 선택을 유지합니다.

실제 IndexedDB 브라우저 검사에서 동시 저장·중복 방지·백업·오래된 백업·초기화/교체 뒤 지연 쓰기 차단과 320/390/1280px 추억 노트를 확인했습니다. 모의 채팅 1회 외에 노트 조작의 AI 호출은 0회입니다. 기본 Web·홈 월드·현재 기능·추억·진화·로컬 AI·7개 테마·구조 지도·위키 회귀, 제공자 단위 6건, Pyodide와 추억 코어 10건이 모두 통과했습니다. 독립 검토 결과는 Ready입니다.

배포 완료: [공개 Web 0.8.0](https://kdkrkwhr.github.io/notebook-pets/) · 런타임 **bd7592b58b096850b45b2bd94ea93e6ac28a0c46** · [Pages 41007524755](https://github.com/kdkrkwhr/notebook-pets/actions/runs/41007524755) 빌드·배포 성공. 최종 Anna 배포 기록과 브라우저 테스트 안정화 커밋 **3739336**도 Git으로 병합했으며 게임·Web 실행 코드는 그대로입니다.

공개 서버의 app.js, worker.js, visuals.js, memories.mjs, memory-text.mjs, home-scene.mjs, home-walk.mjs는 로컬 검증 빌드와 바이트 단위 SHA-256이 일치합니다. core/memories.py는 Windows/Linux 체크아웃 줄바꿈 정규화 후 일치합니다. 공개 구조 지도도 해당 배포 revision을 표시했습니다.

실제 공개 URL의 별도 브라우저 컨텍스트에서 Pyodide로 새 친구를 만들고 첫 만남 1건·추억 노트·새로고침 뒤 같은 기록을 확인했습니다. 320/390/1280px에서 가로 넘침이 없고 닫기 버튼이 보이며, 390px 화면도 직접 확인했습니다. 페이지 오류·외부 요청·실제 AI 호출은 모두 0회입니다. 기존 사용자 프로필과 저장 데이터는 열거나 변경하지 않았습니다.

실물 모바일 기기·스크린 리더와 새 AI 제공자 출력 품질은 이번 검증 범위에 포함하지 않습니다. 과거 누적 승수만 남은 저장에는 이전 첫 승리를 만들지 않으며, 신뢰할 수 있는 기존 기록은 다음 성공한 게임 저장에서 보존됩니다.
