# Web 0.4.1 · 일곱 가지 테마

배포 완료: [공개 웹](https://kdkrkwhr.github.io/notebook-pets/) **0.4.1**. Anna 1.4.4와 같은 테마 선택 창·색상·저장 동작을 공통 파일에서 가져온다.

- 상단 **◐ 테마**에서 기본 공책·고요한 밤·지옥문·얼음왕국·몽환의 숲·침몰한 왕궁·잊혀진 태엽도시를 선택한다.
- 선택 즉시 적용하며 브라우저 로컬 설정에 기억한다. API 키나 AI 요청이 필요하지 않고 IndexedDB 게임·그림 저장소를 수정하지 않는다. 테마는 공책 백업이나 Anna·기기 간 동기화 대상이 아니다.
- 모바일 테마 카드와 헤더, 어두운 대화·도감·홈 상점 색상, 초상화의 원래 색상을 확인한다.

배포 소스 `19dd9c8f6905895b313cf9aaf9b50bfaa2e614e8`. Anna 변경 `bc1110b`를 Git merge로 통합했으며, 이 뒤 문서만 변경한 커밋은 런타임과 동일하다.

- 로컬 Edge의 기존 웹 회귀·홈/던전/이미지/백업 통합·새 테마 시나리오 모두 통과했다. [Pages Chromium 검사·배포](https://github.com/kdkrkwhr/notebook-pets/actions/runs/38845484168) 성공.
- 공개 URL의 별도 Edge 컨텍스트에서 7개 테마, 재실행 유지, 1120/360px, 홈·도감·AI 설정을 확인했다. 게임·아트 저장 스냅샷 동일, AI 요청 0회, 페이지 오류 0. 사용자 브라우저 저장소는 변경하지 않았다.
- 공개 HTML `data-web-version=0.4.1` 확인. 테마·앱·홈·던전·코어·아트 파일 **19개 SHA-256**이 로컬 빌드와 일치한다(텍스트 줄바꿈 정규화).
- Anna는 **1.4.4 / ID 1416 / working revision 58**, 도구 **0.9.1**로 실제 테스트 설치됐다. 기존 심사 후보 1.0.0·소개·스크린샷·개인 저장 데이터는 그대로다. [Anna 배포 기록](../anna/releases/RELEASE_144.md)
