# Web 0.4.1 · 일곱 가지 테마

배포 준비 중. Anna 1.4.4와 같은 테마 선택 창·색상·저장 동작을 공통 파일에서 가져온다.

- 상단 **◐ 테마**에서 기본 공책·고요한 밤·지옥문·얼음왕국·몽환의 숲·침몰한 왕궁·잊혀진 태엽도시를 선택한다.
- 선택 즉시 적용하며 브라우저 로컬 설정에 기억한다. API 키나 AI 요청이 필요하지 않고 IndexedDB 게임·그림 저장소를 수정하지 않는다. 테마는 공책 백업이나 Anna·기기 간 동기화 대상이 아니다.
- 모바일 테마 카드와 헤더, 어두운 대화·도감·홈 상점 색상, 초상화의 원래 색상을 확인한다.

배포와 검증 결과는 완료 후 기록한다.
