    친구의 새 그림

    현재 성장 단계의 그림을 저장해요. 완성된 캐릭터 그림을 골라 주세요. 종족·능력치·성격은 그대로 유지돼요.

    설정한 이미지 AI에 이 그림을 보내 방향별 픽셀 동작을 한 번 만들어요. Gemini는 Google로, ComfyUI는 이 PC로 보내요. 홈·던전이 같은 동작을 공유하며, 이미지 AI가 준비되지 않았으면 그림만 저장해요.

    AI 설정 · 웹 전용

    대화·가구 배치와 이미지 생성을 따로 선택해요. 모두 로컬로 선택하면 Gemini 키가 필요 없어요. AI 없이도 돌봄과 탐험을 즐길 수 있어요.

    키를 입력하고 목록을 불러오면 제공자가 반환한 대화 모델을 선택할 수 있어요.

    참고 그림을 쓰는 워크플로를 ComfyUI에서 먼저 완성하고 API 형식으로 내보내 주세요. 선택한 출력은 4방향 × 4프레임 시트 한 장이어야 해요. 워크플로 파일은 이 탭에서만 사용하며, 다시 열면 재선택해야 해요.

    Gemini를 선택한 기능만 Google에 대화·친구 정보 또는 참고 그림을 직접 보내요. 키 소유자의 요금·할당량을 사용해요. 키는 저장하거나 백업하지 않아요.

    로컬 서버 준비와 접속 허용

    Ollama와 ComfyUI는 이 브라우저와 같은 PC에서 실행해 주세요. 두 서버에서 이 사이트의 출처를 CORS로 허용하고, 브라우저가 로컬 네트워크 접속 권한을 물으면 허용해 주세요.

    연결 확인은 모델 목록·서버 정보만 읽어요. 로컬 요청이 실패해도 Google로 전환하지 않아요. ComfyUI는 로컬 모델만 쓰는 워크플로가 필요해요. 설정 안내
    

    새 친구·새 그림 저장 때만 동작을 한 번 요청해요. 홈 입장·구매·이동에서는 저장된 동작을 사용해요. 연결 전 저장한 그림은 나중에 자동 생성하지 않아요.
    

    공책 보관
    게임은 이 브라우저에만 저장돼요. 브라우저 데이터를 삭제하기 전에 공책을 내려받아 주세요.
    이름과 레벨을 확인한 뒤 현재 공책을 교체해요. 다른 기기와 자동 동기화되지 않으며, 대화는 현재 탭에서만 보여요.
    

    공책을 초기화할까요?
    이 브라우저의 현재 친구와 성장 기록, 재화, 아이템이 모두 지워져요. 현재 탭의 대화와 입력한 API 키도 지워져요. 되돌리려면 미리 내려받은 백업이 필요해요.
