# 프로젝트 위키 · 2026-10-21

GitHub Pages에 `/wiki/`를 추가한다. 한국어 기능 해설 8편, Graphify 자동 문서 42편과 자동 목차 1편을 제공한다. 검색은 정적 문서 색인을 브라우저에서 읽으며 AI 호출·서버·게임 저장소 접근이 없다.

- 탄생·진화, 돌봄·성격, 산책·던전, 홈·픽셀 모습, 공통 코어와 플랫폼별 데이터 경계를 소스와 대조해 설명한다.
- 해설에는 확인한 커밋의 소스 링크를 붙인다. 참조 파일의 SHA-256이 현재 Git 소스와 달라지면 HTML·Markdown·메타데이터에 재검토 필요를 표시한다. 문장 정확성은 자동 검증하지 않는다.
- Graphify 0.9.93의 `export wiki`를 기존 코드 분석 빌드에 연결했다. 그룹이 바뀌면 이전 자동 문서를 제거하고 다시 만든다. 문서 검색 스크립트는 앱 코드 분석에서 제외한다.
- `markdown-it-py==4.0.0`으로 빌드 시 HTML을 생성한다. 본문은 JavaScript 없이도 읽히며 Markdown HTML 삽입은 비활성화한다. 개별 Markdown과 전체 ZIP, 분석 메타데이터를 제공한다.
- 웹 데모 하단·프로젝트 구조 지도·README·문서 목차에서 위키로 연결한다. Anna 앱·도구·심사본과 웹 게임 0.7.1의 규칙 및 데이터 형식은 변경하지 않는다.

검증: `web-wiki.mjs`로 51개 페이지와 112개 로컬 연결, 한글·영문 검색, 자동 문서에서 해설로 이동, 소스 커밋 고정, Markdown·ZIP, JavaScript 비활성화 읽기, 320/390/768/1440px 및 외부 요청 미발생을 확인했다. 실제 데스크톱·모바일 화면도 검토했다. 기존 구조 지도 검사와 웹 실행·저장·CAS·백업·초기화 검사가 통과했다.

빌드 경계 검사 `wiki-build-check.py`도 통과했다. 임시 문서 입력으로 근거 해시 변경 시 HTML·Markdown·메타데이터의 재검토 표시, 근거 미등록 거절, 끊어진 내부 링크 거절을 확인하고 실제 입력을 보존했다.
