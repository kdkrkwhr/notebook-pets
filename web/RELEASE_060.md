# Web 0.6.0 · 2026-10-18

Anna release 3fec4e9까지 Git으로 병합하고 웹 어댑터를 최신 공유 UI와 연결했다. 웹의 저장·BYOK·로컬 제공자 기능을 유지하며, Anna 앱과 심사 후보는 변경하지 않는다.

- 빈 기본 마당, 실내 12종/정원 36종, 상점·내 보관함, 보관 중 개수, PC 분할/모바일 세로 화면, 보조 조작 메뉴와 설명 툴팁.
- 새 친구·그림 저장에서 이미지 자동 호출 제거. 첫 홈에서 명시적인 1회 생성 또는 무료 기본 모습을 선택하고 저장한다. 생성 실패 기본 전환, 이미지 저장만 재시도, 재접속 무호출.
- 공유 이미지 생성기에 플랫폼별 요청 옵션 연결점 추가. Anna의 설명 기반 경로는 유지하고 웹은 Gemini/ComfyUI에 현재 그림을 직접 참조로 보낸다.
- 돌봄 AI 옵션, 선택적 돌봄 반응·산책 이야기, AI를 끈 기본 이야기, 산책 완료 후 던전 발견 표시. 최근 산책 기록은 IndexedDB·백업에 포함한다.
- 기존 공책·그림·가구 저장 형식과 epoch/CAS 보호를 유지한다. 이전 백업도 지원하며 키·워크플로는 저장하지 않는다.

공유 JS 92개 검사와 웹 실제 Pyodide·IndexedDB 검증을 통과했다. 모의 Gemini/Ollama/ComfyUI로 첫 홈 생성 1회, 무료 기본 모습, 저장만 재시도, 잘못된 배치 거부, 초기화 후 늦은 응답 차단을 확인했다. 추가 통합 검사로 빈 마당·정원 36종·보관함·PC/모바일 배치, 돌봄 옵션, 산책 AI 1회와 권위 있는 선택·보상 유지, 던전 발견 순서, 산책 포함 백업 복원을 확인했다. 유료 AI 호출은 없다.

웹은 완성된 그림 업로드를 지원하며 Anna의 그림 분석·AI 탄생은 이식하지 않았다. 채팅과 돌봄 반응은 현재 탭에만 표시한다. 실제 제공자의 유료 이미지 생성 품질은 이번 검증 범위에 포함하지 않았다.
