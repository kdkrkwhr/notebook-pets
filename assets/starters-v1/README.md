# Starter artwork / 기본 이미지

Complete 9-species × 8-element starter set for Anna. Four approved stage-one images from `assets/anchored_evolution` are retained byte-for-byte. The remaining 68 were created with the built-in image generation tool, using the approved images as visual references. Local ComfyUI candidates were excluded after visual comparison; the runtime ComfyUI integration is unchanged.

Open [the gallery](index.html) to inspect every combination. Each JSON sidecar and `manifest.json` records the exact prompt, reference hashes, origin and output hash. Built-in generations do not expose a reproducible seed; no seed or model name is invented. The original provenance is retained for the four copied anchors.

Anna preparation validates complete coverage and hashes before copying this set to `bundle/assets/starters-v1/`. The versioned URL avoids old sample cache entries. These are shared starter images, not personal AI portraits. Existing per-pet portraits, game state and growth history are preserved. Future Anna AI requests use aligned painted-style wording, but that provider can render differently.
