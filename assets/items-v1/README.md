# Notebuddy item art · v1

Twenty-four original pixel-style catalog illustrations: common gear and five dungeon collections. The first sixteen were generated individually with the built-in `image_gen` tool on 2026-10-14; exact prompts are in [prompts.json](prompts.json). Eight Sunken Palace and Forgotten Clockwork City illustrations were added on 2026-10-15 for app 1.1.2; their exact prompts are in [prompts-112.json](prompts-112.json).

The transparent PNG outputs are copied unchanged into this directory and bundled by `anna/scripts/prepare_assets.py`. These are item illustrations, not character try-on results or animated effects. Browsing the catalog never requests AI. The six surrounding-effect icons depict the intended ornament; motion is not implemented in this release.
