# Notebuddy item art · v1

Sixteen original pixel-style catalog illustrations for the common, Hellgate, Ice Kingdom and Dream Forest collections. Generated individually with the built-in `image_gen` tool on 2026-10-14. Exact prompts are recorded in `prompts.json`.

The transparent PNG outputs are copied unchanged into this directory and bundled by `anna/scripts/prepare_assets.py`. These are item illustrations, not character try-on results or animated effects. Browsing the catalog never requests AI. The four surrounding-effect icons depict the intended ornament; motion is not implemented in this release.
