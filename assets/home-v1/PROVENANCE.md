# Home furniture v1

Original transparent 4 × 3 furniture atlas generated with the built-in image generation tool on 2026-10-16 for NoteBuddy. Prompt: warm hand-painted 2D storybook furniture, consistent isometric viewpoint, twelve isolated objects on transparency: pet nest, bookshelf, desk, lamp, round table, rug, cushion, plant, wall art, curtains, tea set and basket. No user artwork was used.

The game renders room geometry, furniture and the existing pet independently. This atlas is not a flattened room background. `atlas.json` records individual sprite bounds. Generation happens during development; runtime furniture rendering makes no image or AI requests.
